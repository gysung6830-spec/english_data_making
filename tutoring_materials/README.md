## 하루 숙제 설계 (약 10~15분)

단어가 잘 안 외워지는 학생을 위해 **난이도 계단 + 반복 노출**로 구성했습니다.

1. **어제 단어 복습** (5개) — 분산 학습(spaced repetition)
2. **오늘의 단어 10개 · 따라 쓰기** — 연한 글씨 덮어쓰기 → 한 번 더 쓰기
3. **짝 맞추기** — 영어 ↔ 뜻 선 잇기
4. **첫 글자 보고 완성** — 철자 부담을 줄인 스캐폴딩
5. **문장 속 빈칸** — 지문 실제 문장 + 단어 상자
6. **오늘의 문법 한 입** — 골라 동그라미 (그날 배운 문법만)
7. **정답** — 학생/보호자가 바로 self-check

## 다시 만들기 / 2주차 추가

```bash
pip install weasyprint          # 최초 1회
cd tutoring_materials
python generate.py              # output/ 에 PDF 재생성
```

- 내용을 고치려면 `content_week1.py`(단어·문장·문법 데이터)만 수정하면 됩니다.
- **2주차(6~9일: The Predator ③④ + 무당벌레 + 지렁이)** 는 `content_week1.py`와
  같은 형식으로 `content_week2.py`를 만들어 동일하게 생성할 수 있습니다.
- 디자인(색상·폰트·레이아웃)은 `generate.py` 상단의 CSS에서 조정합니다.
  폰트는 저장소의 `templates/fonts/NanumSquareRound*.woff` 를 임베드합니다.
