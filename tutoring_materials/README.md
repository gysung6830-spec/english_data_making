# 중등 기초 브릿지 · 과외 숙제 & 테스트 교재 (은아쌤 손글씨판)

**읽기만으로는 안 외워지는 고1 학생**(과거분사도 모르는 수준)을 위한, **쓰기 + 누적 반복 + 친절한 문법** 중심의 한 달 과정 교재입니다.
정답은 **선생님용 별지**로 분리되어 있습니다.

- 지문 출처: 2022 개정 천재(강상구) 공통영어2 · Lesson 1 & 2 · 고1 2학기 내신 대비
- **한 달(4주) 과정으로 1과·2과의 모든 문장(1과 57 + 2과 52)을 직독직해로 다룹니다.**
  - 1주차(1~5일) 1과 전반 · 2주차(6~9일)+10일 총복습 1과 후반
  - 3주차(11~15일) 2과 전반 · 4주차(16~19일)+20일 총복습 2과 후반

## 하루 숙제 구성 (은아쌤 손글씨판 · 약 20분)

각 날짜는 **은아쌤이 옆에서 말해주는 말투**로 쓰여 있습니다 (AI 티 X).

0. **은아쌤 한마디 + 오늘 지문 전체 설명** — 지문 내용을 친절히 풀어서 먼저 이해
1. **지문 내용 확인 (참/거짓)** — 내용을 제대로 읽었는지 한글 T/F 문제로 점검
2. **지난 단어 다시보기** — 어제·그제 단어 12개, 영↔한 섞어서 (누적 반복)
3. **오늘의 단어 10개 · 3가지로 익히기** — ① 소리 내며 **영어+뜻 함께 쓰기** ② 줄 잇기(매칭) ③ 뜻→영어 쓰기
4. **오늘의 문법, 쉽게 이해하기** — 기초 용어부터(과거분사·be동사 등) → 쉬운 일상 예문 → 지문 예문 →
   스스로 발견 → 은아쌤 정리 → 연습. (‘오늘의 문법’은 맨 위 주황 배너로 강조)
5. **직독직해 · 오늘 지문 전체** — 그날 **모든 문장**을 영어+우리말(검은 볼드) 표로 확인
6. **문장 외우기 · 4문장** — ① 덩어리 **순서 넘버링** 영작 → ② 점점 지우기(빈칸 채우기)

## 파일 구조 (`output/`)
- `00_한달_학습플랜.pdf` — 4주 전체 캘린더(1·2과) + 루틴 + 반복 시스템
- `L1_*` / `L2_*` — 과별 요일 숙제(각 학생용+정답 별지), 총복습, 합본, 주차별 단어테스트, 종합테스트
- 콘텐츠 수정: `content_lesson1.py` / `content_lesson2.py` (단어·문법·T/F·문장 데이터)

> 정답은 각 파일 맨 뒤 `✂ 선생님용 정답` 페이지에. 학생에게 줄 땐 그 페이지만 빼면 됩니다.

## 반복(암기) 설계

- **매일**: 누적 복습으로 이전 단어 재노출
- **매주 금요일**: 그 주 단어 전체 테스트
- **2주마다**: 한 과 종합 테스트
- 10일차는 새 단어 없이 배운 것을 **다시 쓰며** 굳히는 총복습일

## 다시 만들기 / 2과(3~4주차) 추가

```bash
pip install weasyprint      # 최초 1회
cd tutoring_materials
python generate.py          # output/ 재생성
```

- 단어·문장·문법 데이터는 `content_lesson1.py` 한 파일에 모여 있습니다.
- **2과**는 같은 형식의 `content_lesson2.py`를 만들어 `generate.py`에서 불러오면 됩니다.
  (2과 원문: 3D 점자지도 / 수어-음성 앱 / 자율주행차 — 문장은 확보되어 있음)
- 디자인은 `generate.py` 상단 CSS에서 조정. 폰트는 `templates/fonts/NanumSquareRound*.woff` 임베드.
