# 중등 기초 브릿지 · 과외 숙제 & 테스트 교재 (쓰기 강화판)

**읽기만으로는 안 외워지는 고1 학생**을 위한, **쓰기 학습 + 누적 반복** 중심의 한 달 과정 교재입니다.
본문 학습지(수업용)를 복습하도록 설계했고, 정답은 **선생님용 별지**로 분리되어 있습니다.

- 지문 출처: 2022 개정 천재(강상구) 공통영어2 · Lesson 1 · 고1 2학기 내신 대비
- 한 달(4주) 과정: **1~2주차 = 1과**, 3~4주차 = 2과(이어서 제작)

## 하루 숙제 구성 (은아쌤 손글씨판 · 약 20분)

각 날짜는 **은아쌤이 옆에서 말해주는 말투**로 쓰여 있습니다 (AI 티 X).

0. **은아쌤 한마디 + 오늘 지문, 무슨 내용이냐면** — 먼저 내용을 이해하고 시작
1. **지난 단어 다시보기** — 어제·그제 단어 12개, 영↔한 섞어서 (누적 반복)
2. **오늘의 단어 10개 · 3가지로 익히기** — 같은 단어를 ① 3번 쓰기 ② 줄 잇기(매칭) ③ 뜻→영어 쓰기
3. **문법, 스스로 찾아보기** — 예문을 보고 규칙을 직접 발견 → 은아쌤 정리 → 연습
   (‘오늘의 문법’은 페이지 맨 위 주황 배너로 크게 강조)
4. **문장 외우기** — ① 청크(끊어읽기) 줄 잇기 → ② 순서대로 이어 쓰기 → ③ 점점 지우기(빈칸이 늘어남)
   (그냥 베껴 쓰기 대신, 덩어리로 이해하고 스스로 채우며 외우기)

> 정답은 각 파일 맨 뒤 `✂ 선생님용 정답` 페이지에. 학생에게 줄 땐 그 페이지만 빼면 됩니다.

## 반복(암기) 설계

- **매일**: 누적 복습으로 이전 단어 재노출
- **매주 금요일**: 그 주 단어 전체 테스트
- **2주마다**: 한 과 종합 테스트
- 10일차는 새 단어 없이 배운 것을 **다시 쓰며** 굳히는 총복습일

## 다시 만들기 / 2과(3~4주차) 추가

```bash
pip install weasyprint      # 최초 1회
cd tutoring_materials
python generate.py          # output/ 재생성
```

- 단어·문장·문법 데이터는 `content_lesson1.py` 한 파일에 모여 있습니다.
- **2과**는 같은 형식의 `content_lesson2.py`를 만들어 `generate.py`에서 불러오면 됩니다.
  (2과 원문: 3D 점자지도 / 수어-음성 앱 / 자율주행차 — 문장은 확보되어 있음)
- 디자인은 `generate.py` 상단 CSS에서 조정. 폰트는 `templates/fonts/NanumSquareRound*.woff` 임베드.
