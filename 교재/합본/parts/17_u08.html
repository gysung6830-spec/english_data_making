UNIT 8

접속사 vs 전치사

뒤만 잘 살피면 바로 해결

1. 결정적 판별 — 뒤가 '절'인가 '구'인가

한 줄 원칙
뒤에 절(주어+동사) → 접속사 / 뒤에 (동)명사구 → 전치사.
"____ + 주어 + 동사 …" → 접속사
"____ + 명사/-ing …" → 전치사

2. 뜻은 같고 품사만 다른 짝(최빈출)

의미접속사(+절)전치사(+명사구)
~때문에because, since, asbecause of, due to, owing to
~에도 불구하고although, though, even thoughdespite, in spite of
~하는 동안whileduring
~라면/아니면if, unless—
because it rained (절)  /  because of the rain (구)
Despite it was cold, we went out.
→ Although it was cold … / Despite the cold, …

3. so/such/so that

구문형태
so ~ thatso + 형/부 + that + 절
such ~ thatsuch + (a) 형 + 명사 + that
so that"~하기 위해"(목적)
▶ 연습문제 (16문항)
유형 A. 접속사/전치사 선택 [1~8]
  1. ( Because / Because of ) the heavy snow, schools closed.
  2. ( Although / Despite ) he was tired, he kept working.
  3. I fell asleep ( during / while ) the movie.
  4. ( During / While ) I was cooking, the phone rang.
  5. We won ( despite / although ) the bad weather.
  6. She succeeded ( because / because of ) her effort.
  7. He stayed calm ( in spite of / even though ) the danger.
  8. Please wait ( until / by ) I come back.
유형 B. so/such 등 [9~12]
  1. It was ( so / such ) a boring lecture that I dozed off.
  2. He was ( so / such ) tired that he fell asleep instantly.
  3. Speak louder ( so that / because ) everyone can hear.
  4. They were ( so / such ) kind people that we felt at home.
유형 C. 밑줄 O/X — 틀리면 수정 [13~16]
  1. In spite of it was raining, the match went on.
  2. He was absent because of he was sick.
  3. We talked during we waited for the bus.
  4. Despite the heavy traffic, we arrived on time.
