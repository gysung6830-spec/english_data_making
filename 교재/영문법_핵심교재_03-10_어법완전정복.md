# Unit 3. 분사 및 태
### 능동 vs 수동 · 분사구문 패턴 체화

## 3-1. 태의 원리 — 주어가 '하는가' vs '당하는가'
- 능동태: 주어가 동작을 **직접 함**. / 수동태: 주어가 동작을 **당함** → **be + p.p. (+ by)**
- The chef **cooked** the meal. → The meal **was cooked** by the chef.

**태 판별 3원칙**
1. 주어가 행위자면 능동, 대상이면 수동.
2. **목적어가 있으면 능동**, 없고 be+p.p.면 수동.
3. **자동사는 수동태 불가**: happen, occur, appear, arrive, exist, consist, seem …
- ✕ The accident *was happened*. → ○ The accident **happened**.

## 3-2. 분사 — 현재분사(능동) vs 과거분사(수동)
| 분사 | 의미 | 예 |
|---|---|---|
| 현재분사 -ing | 능동·진행 "~하는" | a **running** dog / the **exciting** game |
| 과거분사 p.p. | 수동·완료 "~된/당한" | a **stolen** bike / the **excited** fans |

**감정분사:** 감정을 *유발*하면 -ing(boring, interesting, surprising), 감정을 *느끼면* -ed(bored, interested, surprised). 사람 주어는 대개 -ed.
- The movie was **boring**, so the kids were **bored**.

## 3-3. 분사구문 만드는 3단계
1. 접속사를 지운다(의미 강조 시 남겨도 됨).
2. 주절과 주어가 같으면 부사절 주어를 지운다.
3. 동사를 **-ing(능동)** 또는 **(being) p.p.(수동)** 로 바꾼다.
- When she saw the police, she ran away. → **Seeing** the police, she ran away.
- Because it was written in haste, … → **(Being) Written** in haste, …

의미: 시간(when/while) · 이유(because/since) · 조건(if) · 양보(though) · 동시상황(and).
- **with + 명사 + 분사(부대상황):** with her eyes **closed**(수동) / with his dog **following**(능동).
- **현수분사 주의:** 분사의 의미상 주어 = 주절 주어. ✕ *Walking home, the rain started.*

### 3강 연습문제
1. The results were quite ( surprising / surprised ). → **surprising** (사물·능동)
2. The building ( damaging / damaged ) by the fire … → **damaged** (수동)
3. ( Finishing / Finished ) his homework, he went out. → **Finishing**
4. `A strange thing was happened to me.` → happen 자동사 → **happened**
5. `As I didn't know what to say, I remained silent.` → **Not knowing** what to say, I remained silent.
6. `Written in easy English, I could read the book.` → 현수분사 오류 → **As it was written** in easy English, I could read the book.

# Unit 4. 수일치
### 수식어구 · 도치 구문 실전 적용

## 4-1. 대원칙 — 주어의 '핵'에 맞춘다
주어와 동사 사이의 **전치사구·관계절·분사구(거품)** 는 무시하고 **핵 명사**에 일치.
- The **box** of old letters **is** on the table.
- The **students** who study hard **pass** the exam.

## 4-2. 조심할 주어들
| 주어 | 수 | 예 |
|---|---|---|
| 동명사/to부정사/명사절 | 단수 | Reading books **is** fun. |
| each/every + N | 단수 | Every student **has** … |
| either/neither (of) | 단수 | Neither of them **was** … |
| most/some/half of + N | of 뒤 명사 | Most of the water **is** … / Most of the people **are** … |
| a number of + 복수N | 복수(많은) | A number of cars **were** … |
| the number of + 복수N | 단수(~의 수) | The number of cars **was** … |
| the + 형용사 | 복수 | The rich **are** … |

**상관접속사 주어(가까운 쪽 규칙):** both A and B → 복수 / either A or B, neither A nor B, not only A but also B, A as well as B → **B에 일치**.
- Not only you but also **he is** wrong. / Either you or **I am** right.

## 4-3. 도치 구문 — 진짜 주어는 동사 뒤
- There **are** many **reasons**. / On the hill **stands** an old **castle**.
- Never **have I** seen … / Only then **did he** realize …
- Under the tree **were** two **cats**.

### 4강 연습문제
1. The list of the winners ( was / were ) … → **was** (핵 list)
2. Each of the rooms ( has / have ) … → **has**
3. Not only the players but also the coach ( was / were ) … → **was** (B=coach)
4. The number of tourists ( has / have ) … → **has**
5. There ( is / are ) a pen and two books … → **is** (가까운 a pen)
6. `Neither of the answers are correct.` → **is** correct.

# Unit 5. 병렬구조와 비교구문
### 등위·상관접속사 병렬 · 비교 공식

## 5-1. 병렬 — 연결된 것은 '같은 급'
and/but/or로 연결된 요소는 문법적으로 같은 형태.
- ✕ swimming, hiking, and *to run* → ○ swimming, hiking, and **running**.
- 상관접속사도 A와 B의 형태 일치: not only **smart** but also **kind** / either **to stay** or **to leave**.

## 5-2. 비교의 세 형태
원급 `as ~ as`, 비교급 `-er/more ~ than`, 최상급 `the -est/most`.
- **비교 대상 병렬(that/those):** ✕ *milder than Canada* → ○ milder than **that of Canada**.

## 5-3. 자주 나오는 공식
| 공식 | 의미 |
|---|---|
| much/far/even/still + 비교급 | "훨씬"(very 비교급 ✕) |
| the 비교급 ~, the 비교급 ~ | "~할수록 더 …" |
| 배수 + as ~ as / 비교급 than | twice as large as |
| 비교급 and 비교급 | "점점 더" |
| superior/inferior/senior/prior **to** | 라틴 비교(than ✕) |

- ✕ *very faster* → ○ **much/far** faster.

### 5강 연습문제
1. singing, dancing, and ( acting ) → **acting**
2. larger than ( that of India ) → **that of India**
3. ( much ) more difficult → **much**
4. not only a teacher but also ( a novelist ) → **a novelist**
5. superior ( to ) theirs → **to**
6. `The more you sleep, the lazier you become.` → 옳음.

# Unit 6. 대명사와 대동사
### 지칭 오류를 잡아내는 결정적 트레이닝

## 6-1. 대명사 — 선행사와 수·성 일치
- A company should protect **its** (their ✕) employees.
- Every student … **his or her** (규범 문법; 구어는 their 허용).

## 6-2. 재귀·지시대명사
- 재귀 -self: 주어=목적어(She hurt **herself**) / 강조(I did it **myself**).
- that/those: 반복 명사 대신. The ears of a rabbit are longer than **those** of a cat.
- it(바로 그것) vs one(같은 종류의 하나): I lost my pen; I need to buy **one**.
- **one ~ the other**(둘) / **one ~ another ~ the others**(셋 이상) / others(막연한 일부) / the others(나머지 전부).

## 6-3. 대동사 — 동사 반복 회피
일반동사 → **do/does/did**, be·조동사·완료 have는 그 동사 반복.
- He runs faster than I **do**. / She is happier than she **was**.
- **So/Neither 도치:** "So do I"(긍정 동의) / "Neither can I"(부정 동의).

### 6강 연습문제
1. celebrated ( its ) victory → **its**
2. milder than ( that ) of London → **that**
3. one … ( another ) … ( the other ) → **another / the other**
4. "…" — "( Neither ) do I." → **Neither**
5. better than his brother ( does ) → **does**
6. `Everyone raised their hand.` → 규범: **his or her hand**.

# Unit 7. 형용사 vs 부사
### 품사 혼동을 끊어내는 위치 분석법

## 7-1. 역할로 구분
- 형용사: 명사 수식 / 보어(2·5형식). 부사: 동사·형용사·부사·문장 수식(보어 자리 ✕).
- **위치 분석:** 명사 앞·be/감각동사 뒤 보어 → 형용사 / 그 외 꾸밈 → 부사.
- ✕ sings *beautiful* → sings **beautifully**.

## 7-2. 감각·상태동사 + 형용사(2형식)
look/feel/smell/taste/sound/seem/become + **형용사**.
- This soup tastes **good**(✕ well). / You look **tired**(✕ tiredly).

## 7-3. 헷갈리는 부사
hard(열심히)/hardly(거의 ~않다), late(늦게)/lately(최근에), near(가까이)/nearly(거의), high/highly, most/mostly.
- He works **hard** but **hardly** rests.
- **enough 위치:** 형/부 뒤(old **enough**), 명사 앞(**enough** money).

### 7강 연습문제
1. playing ( quietly ) → **quietly**
2. smell ( sweet ) → **sweet**
3. could ( hardly ) believe → **hardly**
4. old ( enough ) to drive → **enough**
5. fluently and ( accurately ) → **accurately**
6. `performed very good` → **very well**

# Unit 8. 접속사 vs 전치사
### 뒤만 잘 살피면 바로 해결

## 8-1. 결정적 판별
- 뒤에 **절(주어+동사)** → **접속사** / 뒤에 **(동)명사구** → **전치사**.

## 8-2. 뜻 같고 품사만 다른 짝
| 의미 | 접속사(+절) | 전치사(+명사구) |
|---|---|---|
| ~때문에 | because, since, as | because of, due to, owing to |
| ~에도 불구하고 | although, though, even though | despite, in spite of |
| ~동안 | while | during |
| ~라면/아니면 | if, unless | — |

- because it rained(절) / because of the rain(구).
- ✕ *Despite it was cold* → **Although** it was cold / Despite **the cold**.

## 8-3. so/such/so that
- so + **형/부** + that / such + **(a) 형+명사** + that / so that(목적 "~하기 위해").

### 8강 연습문제
1. ( Because of ) the heavy snow → **Because of**
2. ( Although ) he was tired → **Although**
3. ( during ) the movie → **during**
4. ( such ) a boring lecture that → **such**
5. ( While ) I was cooking → **While**
6. `In spite of it was late` → **Although** it was late.

# Unit 9. 5형식 · to부정사 · 특수구문
### 고난도 킬러 패턴 집중 공략

## 9-1. 5형식 — 목적격 보어 형태가 관건
| 동사 | 목적격 보어 | 예 |
|---|---|---|
| call/make/find | 명사·형용사 | made me **happy** |
| want/ask/tell/allow | to부정사 | told me **to wait** |
| 사역 make/have/let | 원형부정사 | made him **go** |
| help | 원형/to | helped me (to) **move** |
| 지각 see/hear/watch | 원형/-ing/p.p. | saw her **cross/crossing** |

- ✕ made me *to clean* → made me **clean**. / **get**은 준사역 → get him **to** help.

## 9-2. to부정사 핵심
- 3용법(명사·형용사·부사), 의미상 주어(**for** + 목적격 / 성품 형용사는 **of** + 목적격),
- 가주어–진주어(**It** is hard **to** master …), too~to, 형/부 + enough to.

## 9-3. 특수구문
- **It ~ that 강조**(It was John **that** broke it), 동사 강조(**do/does/did** + 원형),
- 부정어 도치(**Never** have I …), 동격 that(the fact **that** …), 부분 부정(not all/always).
- **강조 vs 가주어 구별:** 강조구문은 It is/was·that을 빼도 문장 성립.

### 9강 연습문제
1. had the students ( write ) → **write** (사역 have+원형)
2. saw a stranger ( enter ) → **enter/entering**
3. kind ( of ) you → **of**
4. ( strong enough ) → **strong enough**
5. ( It ) was in Paris that → **It** (강조구문)
6. `let me to stay up late` → let me **stay**.

# Unit 10. 전범위 누적 최종모의고사 (20문항)

### Part A. 어법 선택 (1~10)
1. studying rare birds ( has / having ) published → **has** *(1강)*
2. the reason ( why / which ) she resigned → **why** *(2강)*
3. The bridge ( building / built ) in 1920 → **built** *(3강)*
4. Neither the manager nor the workers ( was / were ) → **were** *(4강)*
5. colder than ( London / that of London ) → **that of London** *(5강)*
6. Each student … ( their / his or her ) → **his or her** *(6강)*
7. smells ( wonderful / wonderfully ) → **wonderful** *(7강)*
8. ( Despite / Although ) the heavy traffic → **Despite** *(8강)*
9. made me ( run / to run ) → **run** *(9강)*
10. Only after the exam ( I realized / did I realize ) → **did I realize** *(4·9강)*

### Part B. 틀린 곳 수정 (11~16)
11. `Walking …, the sunset was breathtaking.` → 현수분사 → 주절 주어를 사람으로: **…, I found the sunset breathtaking.** *(3강)*
12. The number of applicants **have** → **has** *(4강)*
13. reading, painting, and **to travel** → **traveling** *(5강)*
14. one is white and **another** is black → **the other** *(6강)*
15. very careful **and slow** → carefully **and slowly** *(7강)*
16. In spite of **it was raining** → **the rain** (또는 In spite of→Although) *(8강)*

### Part C. 문장 완성 (17~20)
17. `I met a woman. + Her son teaches …` → **I met a woman whose son teaches at my school.** *(2강)*
18. `Because he was tired, he went to bed early.` → **(Being) Tired, he went to bed early.** *(3강)*
19. `______ is difficult ______ (master) a foreign language.` → **It is difficult to master …** *(9강)*
20. `We first met in 2010.`(in 2010 강조) → **It was in 2010 that we first met.** *(9강)*
