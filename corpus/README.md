# 지문 은행 (passage bank) — 「형광펜 독해」 학습 저장소

넣는 기출 PDF마다 지문을 **추출·분류·축적**해서, 교재가 유형별로 **가장 적합한 지문**을 쓰도록 하는 저장소.

## 원리

```
기출 PDF 넣기
   └→ src/ingest_bank.py
        1) 원본 PDF 보관        → corpus/pdfs/ (해시 파일명, 중복 스킵 / git 제외)
        2) 텍스트 추출·문항 분해 → 번호대·유형 분류 (근거 응집형만, 세부대조형 제외)
        3) 지문·선지 추출 + 신호 점수(fitness) 계산
        4) 누적 저장             → corpus/passage_bank.jsonl  ← 이게 "학습"(git 커밋=영구)
```

## 사용법

```bash
# 기출 PDF 학습(여러 개 가능). 원본 저장 + 은행에 누적
python -m src.ingest_bank 시험지1.pdf 시험지2.pdf

# 은행 현황(유형별 개수 + 대표 지문)
python -m src.ingest_bank --report

# 특정 번호대의 '대표 지문'(최고 신호점수) 보기
python -m src.ingest_bank --pick 31-34
```

## 정답표(정답표.pdf) 자동 인식·연결

정답표 PDF를 넣으면(문서에 "정답표" 포함) 지문이 아니라 **공식 정답**으로 처리한다.

- 시험 식별자(`exam_id`, 예 `2023-06`)를 시험지·정답표 양쪽에서 뽑아 **같은 시험끼리 매칭**.
- 정답표 → `corpus/answer_keys.jsonl` 저장 + **은행의 같은 시험 문항에 정답·배점 back-fill**.
- 시험지를 나중에 넣어도, 이미 저장된 정답표가 있으면 자동으로 정답이 붙는다(순서 무관).
- 정답표는 지문이 아니므로 구문해설 큐(`input/`)에는 공유하지 않는다.
- → 카드의 정답을 **추론이 아니라 공식 정답**으로 채운다. (실측: 2023-06 정답표 45개 → 은행 16문항 연결)

```bash
python -m src.ingest_bank 2023_6월_시험지.pdf 2023_6월_정답표.pdf   # 순서 무관
python -m src.ingest_bank --pick 21     # 대표 지문 + 공식정답 표시
```

## "더 적합한 지문으로 교체" 로직

- 각 지문에 **신호 점수(signal_score)** 를 매긴다: 역접·한정·결론·주장·인과·통념 신호어 개수 × 길이 적합도.
- **신호가 뚜렷할수록 = 형광펜 학습에 적합** → 점수가 높다.
- 같은 유형 슬롯에서 **더 높은 점수의 지문이 들어오면 대표 지문으로 승격**(교체).
- 즉 PDF를 넣을수록 각 유형의 대표 지문이 **점점 더 좋은 것으로 갱신**된다.

## 저장 형식 (passage_bank.jsonl, 한 줄 = 지문 하나)

| 필드 | 뜻 |
|---|---|
| `num` | 문항 번호(18~45) |
| `type` / `band` | 유형 / 번호대 (예: 빈칸추론 / 31-34) |
| `passage` | 추출된 영어 지문 |
| `choices` | ①~⑤ 선지 |
| `signal_score` / `signals` | 신호 점수 / 신호 종류·개수 |
| `length` | 지문 길이 |
| `source_sha` / `source_name` | 출처 PDF 해시 / 파일명 |

## 두 교재가 데이터 공유 — 한쪽에만 올려도 됨

이 은행은 **구문해설 교재(기존 분석 도구)**와 **형광펜 독해 교재**의 **공유 데이터 계층**이다.

```
                ┌──────────────────────────┐
  input/ PDF ──▶│  구문해설 파이프라인(run.py) │──┐
                └──────────────────────────┘  │  best-effort 훅
                                               ▼
                                   corpus/passage_bank.jsonl   ◀── 공유 은행
                                               ▲
                ┌──────────────────────────┐  │
  기출 PDF   ──▶│  ingest_bank.py (형광펜)   │──┘
                └──────────────────────────┘
```

- **구문해설 쪽에 올려도**: `run.py` 처리 루프가 각 PDF를 `ingest_bank.share_pdf()`로 은행에 자동 적재(본 처리를 방해하지 않는 best-effort). → 형광펜 교재가 바로 그 지문을 쓴다.
- **형광펜 쪽에 올려도**: `ingest_bank.py`가 원본을 `corpus/pdfs/`에 보관하고 은행에 적재. → 공유됨.
- **중복 자동 스킵**: 같은 PDF(해시)·같은 문항은 다시 넣어도 한 번만 저장.
- 즉 **어느 도구로 올리든 한 번만 올리면 양쪽이 같은 데이터를 공유**한다.

> 두 교재가 서로 다른 저장소(repo)에 있다면, 이 `corpus/`를 공용 서브모듈이나 공유 데이터 repo로 두고 양쪽이 같은 `passage_bank.jsonl`을 바라보게 하면 된다.

## 보존 정책

- **passage_bank.jsonl = git 커밋** → 세션·컨테이너가 초기화돼도 학습 결과 유지.
- **원본 PDF(corpus/pdfs/) = git 제외**(저작권·용량). 로컬 보관용. 필요 시 `corpus/.gitignore`에서 `pdfs/` 줄을 지우면 원본도 함께 커밋됨.
