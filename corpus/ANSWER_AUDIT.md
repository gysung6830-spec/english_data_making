# 정답 정확도 감사 (Answer Accuracy Audit)

교재 87문항의 정답을 **저장소 안의 공식 자료(`corpus/pdfs/`의 평가원 정답표·해설 PDF)** 와 대조했다.
평가원 시험지는 **홀수형·짝수형** 두 판형이 있고 일부 문항은 선지 배열이 달라 **정답 번호가 서로 다르다.**
따라서 각 문항을 **홀수형/짝수형 양쪽**과 대조하여, **둘 중 하나라도 일치하면 정답**으로 판정했다.

## 판정 결과
- **공식 정답과 일치(검증 완료): 72문항**
  - 2024학년도 수능·2023학년도 수능의 22·23·24·40·32 등은 **짝수형** 정답표와 정확히 일치
    (예: 2024수능 22=②·23=④·24=① = 짝수형 / 2023수능 40=② = 짝수형).
  - 2022학년도 수능 23=⑤·24=① = 해설 PDF와 일치.
- **오류 발견·수정: 1문항**
  - **2025학년도 6월 35번(무관한 문장)** — 교재가 ③으로 잘못 표기되어 있었음.
    저장소 해설 PDF의 공식 정답은 **④**(“새소리 연구 → 노래 학습은 선호·한계로 형성” 성격의 외형·번식 문장이 무관).
    → 교재를 **④로 수정**하고, 선지 배열·도출·해설을 ④ 기준으로 일관되게 정리함.

## 요약문(40번) 선지 원문 복원 — 7문항
요약문 6문항은 **오답 선지가 재구성(fabricated)** 되어 있었다. 저장소의 **문제지 PDF**에서
실제 40번의 요약 문장과 **5개 (A)/(B) 선지 원문**을 추출해 **전부 실제 기출 선지로 교체**했다.
- 지문은 이미 실제 기출(문제지와 대조해 일치 확인). 선지만 원문으로 복원.
- 정답 번호는 정답표와 일치(2023수능 40=②는 짝수형): 2024수능①·2026-06②·2024-06②·2023-06①·2026-09④·2023수능②.
- **2027학년도 6월 40번**: 정답표가 없어 번호는 미검증이나, 선지 원문은 문제지에서 복원(정답 ⑤=disregard…underserved는 문맥상 확정적).
- 교체 예) 2026-06: ①burdens→**emptiness**, ⑤fulfilment→**growth** / 2024-06: ③environments→**genes**, ⑤environments→**traits**
  / 2023-06: ③cohesion→**consciousness** / 2026-09: ③preservation→**variation** / 2024수능: ①produces→**enables**
  / 2027-06: ②privileged→**general**, ③affluent→**native** / 2023수능: ①enhance→**cultivate**.
