# 평가원 패러프레이징 출제원리 (실증 분석)

> 근거: 지문 은행의 **실제 평가원 기출 선지 36문항 · 오답 144개**를 유형별로 분류해 도출.
> 함축·주제·제목·빈칸 유형(정답이 지문을 paraphrase하는 유형) 대상.

## 1. 정답 선지 = 지문을 이렇게 바꾼다 (변환 방식 분포)

| 변환 방식 | 비중 | 설명 |
|---|---|---|
| 압축·일반화 | 36% | 여러 문장의 요지를 한 명제로 압축 (요지·주제·제목) |
| 비유→직설 | 22% | 지문의 비유·관용 표현을 직설적 개념으로 (함축에서 특히) |
| 동의어·유의어 치환 | 22% | 핵심어를 같은 뜻 다른 단어로 |
| 구체→추상(상위어) | 14% | 지문의 구체 사례를 포괄 개념으로 |
| 반대구조 재진술 | 6% | not A but B → B, 부정↔긍정 |

→ **정답은 "지문 단어를 그대로 두지 않는다."** 표현을 바꾸되 명제(뜻)를 보존한다.

## 2. 오답 선지 = 이런 함정이다 (실제 평가원 오답 144개 분류)

| 함정 유형 | 비중 | 만드는 법 |
|---|---|---|
| 🎯 초점 이탈·미언급 | **49%** | 지문에 근거 없는 진술 / 주제에서 벗어난 부분·상식적 서술 — **가장 흔함** |
| 🔄 뜻 반대·상반 | 24% | 인과·평가·태도의 방향을 뒤집음 |
| 🌀 세부 왜곡 | 15% | 대상·조건·정도를 슬쩍 비틂 (부분적으로만 맞음) |
| 🚫 표면어휘 복사 | 6% | 지문 단어를 그대로 써 익숙하지만 논리가 어긋남 |
| 📈 범위 초과(과확장) | 4% | 지문 근거를 넘어 더 포괄적·단정적으로 확대 |

## 3. 핵심 발견 — '극단어 = 오답'은 평가원 원리가 아니다

- 극단어(all·always·every·only·forever…)를 쓴 선지: **평가원 오답 144개 중 5개(3%)**, 심지어 **정답 선지에도 1개** 존재.
- 즉 "극단적 표현이 있으면 오답"은 **사설·토익식 heuristic**이지 평가원 판별 원리가 아니다.
- 평가원 오답은 극단어가 아니라 **"지문 근거와의 관계"**(방향·범위·초점)로 만들어진다.
- 오답을 고르는 실제 기준: ① 지문에 그 진술의 근거가 있나 ② 방향(인과·평가)이 지문과 같나 ③ 범위가 지문에 맞나(넓지도 좁지도 않게).

## 4. 교재 반영

- **실전편(36문항)**: 정답·오답 전부 실제 평가원 선지 → 위 원리를 그대로 체득.
- **기초편(80문항)**: 극단어에 의존하던 '과장' 오답 67개를 **범위 초과(개념 과확장, 극단어 없음)**로 전량 교정.
- **방법론 페이지**: 오답 유형을 위 실측 분포로 교체 + '극단어=오답' 오해 경고 삽입.
