검색 등록

네이버·구글에서 우리 자료가 검색되게 만드는 화면입니다. 한 번만 해 두면 됩니다.

왜 해야 하냐면
  1. 등록하지 않으면 네이버·구글이 이 사이트가 있는 줄도 모릅니다.
  2. 등록해도 검색에 뜨기까지 2주에서 3개월 걸립니다. 그래서 빨리 해 두는 편이 좋습니다.
  3. 지금 검색에 걸릴 수 있는 페이지가 {{ page_count }}장 있습니다. 무료 자료를 한 건 올릴 때마다 한 장씩 늘어납니다.

1단계 — 네이버 가장 중요

한국 선생님들은 대부분 네이버로 찾습니다. 여기부터 하세요.
  1. 네이버 서치어드바이저 접속 → 네이버 아이디로 로그인
  2. 웹마스터도구 → 사이트 등록 에 아래 주소를 붙여 넣기
    {{ home_url }}
  3. HTML 태그 방식을 고르면 <meta ... content="긴 글자"> 를 줍니다. 그 줄을 통째로 복사해서 아래 칸에 붙여 넣으세요.
  4. 저장한 뒤 네이버 화면에서 소유확인 버튼을 누르면 끝입니다.
  5. 마지막으로 사이트맵 제출 에 아래 주소를 넣어 주세요.
    {{ home_url }}/sitemap.xml
✅ meta 태그를 통째로 붙여 넣어도 코드만 알아서 뽑아냅니다.

2단계 — 구글

PDF 자료는 구글에서도 많이 찾습니다.
  1. 구글 서치콘솔 접속 → 구글 계정으로 로그인
  2. URL 접두어 쪽에 아래 주소를 넣기
    {{ home_url }}
  3. 확인 방법에서 HTML 태그 를 고르고, 나온 줄을 아래에 붙여 넣기
  4. 저장 뒤 구글 화면에서 확인 → Sitemaps 에 sitemap.xml 제출

3단계 — 다음(카카오)

확인 코드가 필요 없습니다. 주소만 넣으면 끝입니다.
  1. 다음 검색등록 에서 아래 주소를 신청
    {{ home_url }}

이미 해 둔 것 — 손대실 필요 없습니다

아래는 제가 코드에 미리 넣어 두었습니다.
sitemap.xml 검색엔진에게 주는 페이지 목록. 자료를 올리면 자동으로 늘어납니다. 보기 ↗
robots.txt 관리자 화면·다운로드 주소는 검색에 안 걸리게 막아 두었습니다. 보기 ↗
대표 주소(canonical) 같은 화면이 여러 주소로 잡혀 점수가 나뉘는 것을 막습니다.
가격 표시(구조화 데이터) 구글 검색 결과에 가격이 함께 뜨게 하는 표시입니다.
공유 썸네일(og) 카톡·밴드에 링크를 붙이면 그림과 설명이 뜹니다.

💡 검색보다 빠른 길

검색은 2~3개월 걸립니다. 그동안은 아래가 훨씬 빠릅니다.

1. 네이버 카페 — 전국영어교사모임 같은 곳에 무료 자료 링크를 올리세요. 그날 바로 옵니다.
2. 네이버 블로그 — 무료 자료를 블로그에 먼저 올리고 사이트로 링크하세요. 네이버는 자기네 블로그를 검색에서 먼저 보여 줍니다.
3. 무료 자료를 꾸준히 — 회차마다 하나씩 올리면 검색에 걸리는 문이 그만큼 늘어납니다. 지금 {{ free_count }}건 올려 두셨습니다.
