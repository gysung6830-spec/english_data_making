# 동형모의고사 출제원리 · 우선순위 (확정본)

각 유형이 "정답을 어떻게 만들고 / 오답을 어떻게 만들고 / 지문을 어떻게 표시하는지"를
확정한 문서입니다. 코드(`mockexam/generators/*.py`, `base.py`)의 실제 지시문과 일치합니다.

---

## A. 공통 우선순위 (모든 유형에 순서대로 적용)

생성·검증은 아래 우선순위로 보장됩니다. 위 항목이 먼저입니다.

| 순위 | 원칙 | 처리 방식 |
|---|---|---|
| 1 | **구조 요건** (밑줄·빈칸·(A)(B)(C)·①~⑤) | 없으면 생성 단계에서 자동 재작성 |
| 2 | **정답 유일성** (복수정답 금지) | 생성 시 자가검증 + 의심문항만 2차 재검수 |
| 3 | **오답 구성 원리** (유형별, 아래) | 프롬프트로 강제 |
| 4 | **지문 넘버링 규칙** | 무관문장·어법·어휘만 ①~⑤, 나머지는 번호 제거 |
| 5 | **난이도 일관성** | 요청 난이도(상/중/하)에 맞춰 어휘·함정 조절 |
| 6 | **정답 번호 분산** | 한 번호 쏠림·3연속 방지(선지 순서 교환) |
| 7 | **출처 흔적 제거** | WORKBOOK·지문번호·각주·한자 등 제거 |
| 8 | **항상 출력** | 실패해도 PDF 생성, 실패 문항은 맨 끝 '검토 문항' 페이지에 정리 |

**공통 원리 상수** (`base.py`)
- `DISTRACTOR_RULE` — 정답=유의어 패러프레이즈 / 오답 4개=2 무관 + 2 모순(지문 단어 활용)
- `FACT_TWIST` — 주체·인과·부정↔긍정·수치/시점 중 '하나만' 비틀기
- `ESSAY_UNIQUE` — 서술형: 모범답안 1개 + 채점 조건 명시
- `ESSAY_ARRANGE_UNIQUE` — 배열영작: 성립하는 어순이 정확히 1개

## B. 선다형(18문항) 출제원리

### B-1. 의미 이해형 — 정답=유의어, 오답=2 무관 + 2 모순
| 유형 | 정답 구성 | 오답 4개 | 선지 |
|---|---|---|---|
| **요지** main_point | 지문 논지를 유의어로 | 2 무관 + 2 모순 (지문 단어 활용) | 한국어 |
| **제목** title | 지문 논지를 유의어로 | 2 무관 + 2 모순 | 영어 |
| **빈칸** blank_single | 빈칸에 들어갈 올바른 말(유의어) | 2 무관 + 2 모순 | 영어, 결론부를 `____` |
| **함의** implied_meaning | 밑줄 표현을 문맥 재해석 | 표면적/축자적 오독(무관·모순) | 영어, 밑줄 `<u>` |

### B-2. 사실 확인형 — 비틀기(FACT_TWIST)
| 유형 | 정답(고를 것) | 오답 4개 |
|---|---|---|
| **내용 불일치** inference_mismatch | 주체·인과·부정↔긍정·수치/시점 하나 비틀기 | 지문 사실 정확 반영(참) |
| **대화 불일치** dialogue_mismatch | (대화 기준) 위와 동일 · 대화문 없으면 일반 불일치로 전환 | 대화 사실 정확 반영 |
| **안내문 일치** notice_match | 안내문 사실 정확 반영 1개 | 나머지 4개를 비틀기 · 안내문 없으면 일반 일치로 전환 |

### B-3. 번호 선지형 (지문에 ①~⑤ 표시, 선지=번호)
| 유형 | 정답 | 나머지 |
|---|---|---|
| **어법** grammar | 규칙 위반 1곳(수일치·시제·태·관계사·분사…) | 완전히 맞음(각기 다른 문법 포인트), '맞는데 틀린 듯' 함정 |
| **어법+어휘** grammar_vocab_mix | = 어법과 동일(순수 어법 오류 1곳) | 〃 |
| **어휘** vocab_odd | 반의어/오용어 1개 | 원단어를 유의어로 치환(암기로 못 맞히게) |
| **무관문장** irrelevant_sentence | 소재는 겹치나 논지에 무관한 1문장 | 지문 각 문장 앞 ①~⑤ |

### B-4. 조합·구조형
| 유형 | 원리 |
|---|---|
| **어휘 3칸** vocab_3blank_abc | (A)(B)(C) 각 칸 정답1+유의어함정1, **세 칸 모두** 판단해야 정답 1개. 선지=(A)-(B)-(C) 조합 |
| **순서** order | 도입문 고정 + (A)(B)(C) 재배열. 결속 단서(연결사·지시어·정관사·대명사)를 **2개 이상** 심어 순서 유일 확정 |
| **요약 A/B** summary_ab | 요약문 1문장에 (A)(B) 빈칸, 각 칸 유의어 함정, **두 칸 모두** 판단해야 정답 1개. 선지='(A)낱말 - (B)낱말' |

## C. 서술형(9문항) 출제원리

> 공통: **모범답안 1개 + 채점 조건 명시**. 배열영작류는 **성립 어순이 1개**인지 자가검증.

| 유형 | 핵심 원리 |
|---|---|
| **전치사+해석** prep_find_and_translate | 두 빈칸에 **같은 전치사 1개만** 성립, 밑줄문장 직역 모범답안 1개 |
| **어법수정+영답** grammar_fix_and_answer | 밑줄 3곳 **명백한 오류**, 고친 정답 유일 + 영어질문에 본문 근거 영답 |
| **대화 배열영작** dialogue_arrange_inflect | 보기 단어 전부 활용, 동사는 원형 제시→학생이 시제·수·태 변형 |
| **조건 어형변형** condition_write_inflect | 괄호 단어 **한 어형만** 성립, 본문 단어만으로 영답 |
| **요약 빈칸** summary_fill_from_text | 본문 **핵심어 1개**로만 확정, 변형 금지 |
| **배열영작** word_arrange | 보기 배열로 빈칸 완성, 관계사절·부정사 등 구조로 어순 고정 |
| **배열영작+우리말답** arrange_and_translate | 보기로 밑줄 우리말 영작(추가어는 관사·전치사 등 **기능어만**) + 본문 우리말 답 |
| **도표 수정+배열** chart_fix_and_arrange | 도표 있으면 표-서술 어긋난 1곳 수정, **없으면**(날조 금지) 본문 사실 어긋난 1곳 + 배열영작 |
| **보기 골라 빈칸** blank_choose_no_change | 각 빈칸 **문맥상 하나로만** 확정, 함정 단어 2~3개, 변형 금지 |

## D. 지문 넘버링 규칙

| 지문에 ①②③ 삽입 | 지문에 번호 없음 |
|---|---|
| 무관문장(문장 ①~⑤) · 어법 · 어휘(밑줄 ①~⑤) | 그 외 전 유형(내용일치·요지·제목·빈칸·순서·요약 등) |
