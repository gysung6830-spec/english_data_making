# 동형모의고사 출제원리 · 우선순위 (확정본)

각 유형이 "정답을 어떻게 만들고 / 오답을 어떻게 만들고 / 지문을 어떻게 표시하는지"를
확정한 문서입니다. 코드(`mockexam/generators/*.py`, `base.py`)의 실제 지시문과 일치합니다.

---

## A. 공통 우선순위 (모든 유형에 순서대로 적용)

생성·검증은 아래 우선순위로 보장됩니다. 위 항목이 먼저입니다.

| 순위 | 원칙 | 처리 방식 |
|---|---|---|
| 1 | **구조 요건** (밑줄·빈칸·(A)(B)(C)·①~⑤) | 없으면 생성 단계에서 자동 재작성 |
| 2 | **정답 유일성** (복수정답 금지) | 생성 시 자가검증 + 의심문항만 2차 재검수 |
| 3 | **오답 구성 원리** (유형별, 아래) | 프롬프트로 강제 |
| 4 | **지문 넘버링 규칙** | 무관문장·어법·어휘만 ①~⑤, 나머지는 번호 제거 |
| 5 | **난이도 일관성** | 요청 난이도(하·중·중상·상 4단계)에 맞춰 어휘·함정 조절 |
| 6 | **정답 번호 분산** | 한 번호 쏠림·3연속 방지(선지 순서 교환) |
| 7 | **출처 흔적 제거** | WORKBOOK·지문번호·각주·한자 등 제거 |
| 8 | **항상 출력** | 실패해도 PDF 생성, 실패 문항은 맨 끝 '검토 문항' 페이지에 정리 |
| 9 | **판매용 엄격 인증**(선택) | 의심문항을 반복 재검수·재생성 → 그래도 남으면 **출력물에서 ⚠·검토페이지 제거**(배부물엔 주의표시 0), 미인증 문항은 판매자에게만 보고 |
| 10 | **하이브리드 모델** | 생성=Sonnet(빠름·저비용), **2차 검수=Opus**(치명적 정답 오류 최종 차단). `MOCK_MODEL`·`MOCK_REVIEW_MODEL` 로 교체(같게 두면 단일 모델) |

**공통 원리 상수** (`base.py`)
- `DISTRACTOR_RULE` — 정답=핵심 주장 재진술(주제문·역접 뒤) / 오답=평가원식 5축(범위·방향반전·표면어휘·근거없음·초점이동), 2 무관 + 2 모순, 그중 1개는 '매력적 오답'
- `ROLE_TAG_RULE` — 의미형은 선지별 역할(`choice_roles`: 정답/무관/모순)을 출력 → **정답1·무관2·모순2 구조를 자동 검증**(위반 시 재작성)
- `CHOICE_BALANCE_RULE` — 5개 선지 길이·형태를 비슷하게(정답이 길이만으로 드러나지 않게) → **정답 길이 이상치 자동 감지**(재작성)
- `FACT_TWIST` — 주체·인과·부정↔긍정·수치/시점 중 '하나만' 비틀기
- `ESSAY_UNIQUE` — 서술형: 모범답안 1개 + 채점 조건 명시
- `ESSAY_ARRANGE_UNIQUE` — 배열영작: 성립하는 어순이 정확히 1개
- `ESSAY_CONDITION_FORMAT` — `<조건>` 표준 양식: ①사용 단어 범위 ②어형 변화 허용 ③분량(단어수/문장수) ④감점 기준

### A-1. 난이도 4단계 정의 (`system_prompt`에 주입)

| 단계 | 정의(출제 의도) | 실제 구현 |
|---|---|---|
| **하** | **문제를 풀면서 학습이 되도록** — 미리 공부 안 해도 지금 지문을 읽으며 풀 수 있고, 푸는 과정에서 핵심이 익혀짐 | 단서 명시(추론 1단계), 오답 명백, 쉬운 어휘 |
| **중** | **지문을 미리 공부해야 풀 수 있음**(내신 암기 대비형) — 세부 정보·정확한 표현을 알아야 정답이 갈림 | 대충 읽으면 고를 유의어·유사 정보 함정, 표준 수능 어휘 |
| **중상** | **중·상 문항을 반반 배치** — 한 시험(회차) 안에서 절반은 중, 절반은 상 | 문항마다 중/상을 교차 배정해 생성(약 50:50) |
| **상** | **지문에 대한 깊은 이해 필요** — 암기로는 부족, 논지·함의·인과·의도를 종합·적용 | 추론 2~3단계, 근접 오답, 추상 핵심 빈칸, 축자 오독 함정 |

> **난이도 '중'은 유형군별로 적용**(출제원리 정합성):
> - **사실·암기형**(내용일치·어휘·어법·안내문·대화): "세부 정보·정확한 표현을 알아야 풀림" = 정의 그대로.
> - **이해·추론형**(요지·제목·빈칸·함의·순서·무관문장·요약): 지엽 암기가 아니라 **오답 유의어를 촘촘히 해 정밀 독해**로 난이도를 준다. **지엽·부분 정보를 정답으로 삼기 금지**(요지·제목 유형과 충돌 방지). 하·상은 모든 유형 공통.
>
> **'고난도 어휘' 상한** — 수능 빈출 고급어 수준까지만(사전 없이 못 읽는 초저빈도어·전문용어 금지). **지문을 억지로 어렵게 바꾸지 않고**, 어려움은 선지·오답·과제에서만 준다.
>
> **상 난이도 안전장치** — 근접 오답으로 인한 복수정답 위험이 커, ①근접 오답이 있으면 확실히 틀리게 고치거나 `answer_confidence='주의'` 강제, ②**모든 상 선다형을 2차 재검수**(통과 시 ⚠ 없이 정리).

## B. 선다형(18문항) 출제원리

### B-1. 의미 이해형 — 정답=재진술, 오답=평가원식 5축

**정답 위치**: 주제문·반복 어구·역접(But/However) 뒤 **필자 주장**을, 지문 단어가 아닌 다른 말로 재진술.
**오답 5축**: ①범위(너무 넓게/좁게) ②방향 반전 ③표면 어휘 함정(지문 단어 복사, 논점 아님) ④근거 없음 ⑤초점 이동. → **2 무관(③④⑤) + 2 모순/범위(①②)**, 그중 **1개는 '매력적 오답'**(정답과 범위·방향이 한 끗 차이).
**추상화 사다리**: 요지 < 주제 < 제목 (수사·추상도 상승).

| 유형 | 정답 구성 | 선지 |
|---|---|---|
| **요지** main_point | 필자 주장(so what)을 **한국어 완결문**(당위·평가) | 한국어 |
| **주제** topic | '무엇에 관한 글인가'를 **영어 명사구**(범위 적정) | 영어 |
| **제목** title | 주제의 **비유적 재진술**(수사·의문형·콜론, 태도 ±) | 영어 |
| **빈칸** blank_single | 핵심 결론부 재진술 | 영어, 결론부 `____` |
| **함의** implied_meaning | 밑줄의 **함축**(방향 ± + 주제 동시 만족) | 영어, 밑줄 `<u>` (오답=축자/방향반전/과대/부분/무관) |

### B-2. 사실 확인형 — 비틀기(FACT_TWIST)
| 유형 | 정답(고를 것) | 오답 4개 |
|---|---|---|
| **내용 불일치** inference_mismatch | 주체·인과·부정↔긍정·수치/시점 하나 비틀기 | 지문 사실 정확 반영(참) |
| **대화 불일치** dialogue_mismatch | (대화 기준) 위와 동일 · 대화문 없으면 일반 불일치로 전환 | 대화 사실 정확 반영 |
| **안내문 일치** notice_match | 안내문 사실 정확 반영 1개 | 나머지 4개를 비틀기 · 안내문 없으면 일반 일치로 전환 |

### B-3. 번호 선지형 (지문에 ①~⑤ 표시, 선지=번호)
| 유형 | 정답 | 나머지 |
|---|---|---|
| **어법** grammar | 규칙 위반 1곳(수일치·시제·태·관계사·분사…) | 완전히 맞음(각기 다른 문법 포인트), '맞는데 틀린 듯' 함정 |
| **어법+어휘** grammar_vocab_mix | = 어법과 동일(순수 어법 오류 1곳) | 〃 |
| **어휘** vocab_odd | 어색한 낱말 1개 — **난이도 연동**: 하=정답 반의어·나머지 원문 / 중=정답 반의어·나머지 유의어 / 상=미묘한 반의어·연어 오류 (부정어 삽입 X) | 밑줄 ①~⑤ |
| **무관문장** irrelevant_sentence | 소재는 겹치나 논지에 무관한 1문장 | 지문 각 문장 앞 ①~⑤ |
| **문장삽입** insert | 빼낸 문장이 '원래 자리'에만 들어가게(연결사·지시어 단서 2개+) | `[주어진 문장]` 박스 + 위치 ①~⑤ |
| **어법 복수정답** grammar_multi | 밑줄 5곳 중 **2~3곳**을 서로 다른 문법 포인트로 틀리게 → **모두 고르기**(정답=집합 예 `② ④`) | 밑줄 ①~⑤ |
| **어법·어휘 짝짓기** pair_odd | 밑줄 5곳 중 **정확히 2곳**(1 어법 + 1 어휘 반의어)만 부적절, 나머지 3곳 자연스럽게 | 밑줄 ①~⑤, 선지=두 밑줄의 짝(`①-③`) |
| **내용일치 개수형** count_match | 한국어 진술 5개 각각 일치/불일치 명확히 → 정답=**일치 개수**(1~5). 불일치는 주체·정도·인과 뒤집기/미언급 | `[보기]` 박스 ①~⑤ + 선지 `1개~5개`(순서 고정) |

### B-4. 조합·구조형
| 유형 | 원리 |
|---|---|
| **어휘 3칸** vocab_3blank_abc | (A)(B)(C) 각 칸 정답1+유의어함정1, **세 칸 모두** 판단해야 정답 1개. 선지=(A)-(B)-(C) 조합 |
| **순서** order | 도입문 고정 + (A)(B)(C) 재배열. 결속 단서(연결사·지시어·정관사·대명사)를 **2개 이상** 심어 순서 유일 확정 |
| **요약 A/B** summary_ab | 요약문 1문장에 (A)(B) 빈칸, 각 칸 유의어 함정, **두 칸 모두** 판단해야 정답 1개. 선지='(A)낱말 - (B)낱말' |

## C. 서술형(9문항) 출제원리

> 공통: **모범답안 1개 + 채점 조건 명시**. 배열영작류는 **성립 어순이 1개**인지 자가검증.

| 유형 | 핵심 원리 |
|---|---|
| **전치사+해석** prep_find_and_translate | 두 빈칸에 **같은 전치사 1개만** 성립, 밑줄문장 직역 모범답안 1개 |
| **어법수정+영답** grammar_fix_and_answer | 밑줄 3곳 **명백한 오류**, 고친 정답 유일 + 영어질문에 본문 근거 영답 |
| **대화 배열영작** dialogue_arrange_inflect | 보기 단어 전부 활용, 동사는 원형 제시→학생이 시제·수·태 변형 |
| **조건 어형변형** condition_write_inflect | 괄호 단어 **한 어형만** 성립, 본문 단어만으로 영답 |
| **요약 빈칸** summary_fill_from_text | 본문 **핵심어 1개**로만 확정, 변형 금지 |
| **배열영작** word_arrange | 보기 배열로 빈칸 완성, 관계사절·부정사 등 구조로 어순 고정 |
| **배열영작+우리말답** arrange_and_translate | 보기로 밑줄 우리말 영작(추가어는 관사·전치사 등 **기능어만**) + 본문 우리말 답 |
| **도표 수정+배열** chart_fix_and_arrange | 도표 있으면 표-서술 어긋난 1곳 수정, **없으면**(날조 금지) 본문 사실 어긋난 1곳 + 배열영작 |
| **보기 골라 빈칸** blank_choose_no_change | 각 빈칸 **문맥상 하나로만** 확정, 함정 단어 2~3개, 변형 금지 |

## F. N회분(반복 학습) 생성 원리

지문 1세트로 여러 회차를 만들 때(웹앱 '생성 회차 수' 1~4). 각 회차는 학교 blueprint
전체(완결형)를 그대로 생성한다.

- **지문 동일** — 모든 회차가 같은 지문 풀을 그대로 사용(분할하지 않음).
- **문항 비겹침** — 회차 간 **(지문 × 유형) 조합을 누적 회피**한다(`avoid_pairs`).
  지문이 넉넉하면 회차 간 겹침 **0**. 조합이 부족하면(지문 少) 최후에만 재사용하되,
  **회차 변형 지시**(`_variant_hint`)로 정답 지점·선지·표현을 새로 구성해 문항 내용은
  반드시 다르게 만든다.
- **난이도 사다리(고정)** — 회차별 난이도를 아래로 고정한다(1회분만 선택 난이도 사용).

| 회차 수 | 회차별 난이도 |
|---|---|
| 1회 | 선택한 난이도 |
| 2회 | 중 · 중상 |
| 3회 | 중 · 중상 · 상 |

## G. 결과물 재사용(제목만 수정)

분석이 끝난 결과는 `*.exam.json`으로 함께 저장된다. 이 파일을 '제목만 수정' 탭에
올리면 **API 재분석 없이**(비용 없음) 제목·과목·파일명만 바꿔 PDF를 재출력한다.
문항·정답·해설은 그대로 유지된다.
