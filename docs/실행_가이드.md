# 다른 컴퓨터에서 실행하기 (설치 → 실행)

영어 시험지 자동 생성 웹앱을 새 컴퓨터에서 돌리는 방법입니다.
**필요한 것:** ① Python 3.10 이상 ② Git ③ (실제 생성 시) Anthropic API 키.
지문 폰트(나눔스퀘어라운드)는 PDF에 **임베드**돼 있어 따로 설치할 필요가 없습니다.

---

## 0. 코드 내려받기

```bash
git clone https://github.com/gysung6830-spec/english_data_making.git
cd english_data_making
git checkout claude/english-exam-generator-9y3r1x   # 최신 작업 브랜치
```
> ZIP으로 받았다면 압축을 풀고 그 폴더에서 아래를 진행하세요.

---

## 1. 설치

### 🐧 Linux (Ubuntu/Debian) · 🍎 macOS — 한 번에
```bash
bash setup.sh
```
`setup.sh` 가 (1) 시스템 라이브러리 (2) 파이썬 패키지 (3) `.env` 파일을 자동 준비합니다.

### 수동 설치(또는 setup.sh 가 안 되는 경우)

**① 시스템 라이브러리** — PDF 렌더 엔진 WeasyPrint 가 씁니다. **없으면 PDF 생성이 실패**합니다.

- Ubuntu/Debian:
  ```bash
  sudo apt-get update
  sudo apt-get install -y libpango-1.0-0 libpangocairo-1.0-0 \
      libgdk-pixbuf-2.0-0 libffi-dev libcairo2 shared-mime-info poppler-utils
  ```
- macOS (Homebrew):
  ```bash
  brew install pango gdk-pixbuf libffi cairo poppler
  ```
- 🪟 **Windows**: 아래 **Windows 전용 절차**를 따르세요.

---

## 🪟 Windows 전용 절차 (자세히)

두 가지 길이 있습니다. **A(WSL2)가 가장 쉽고 안정적**이며, B는 순수 Windows입니다.

### 방법 A — WSL2(우분투)로 실행 【권장】
Windows 안에서 리눅스를 쓰는 방식이라 WeasyPrint 설치가 훨씬 간단합니다.
1. 관리자 PowerShell에서 `wsl --install` 실행 후 재부팅 → Ubuntu 실행(사용자/비번 설정).
2. Ubuntu 터미널에서:
   ```bash
   sudo apt-get update && sudo apt-get install -y git python3 python3-pip python3-venv
   git clone https://github.com/gysung6830-spec/english_data_making.git
   cd english_data_making
   git checkout claude/english-exam-generator-9y3r1x
   bash setup.sh
   python3 webapp.py
   ```
3. Windows 브라우저에서 **http://127.0.0.1:5000** 접속(WSL2는 자동 포워딩됨).

### 방법 B — 순수 Windows에서 실행
1. **Python 3.10+ 설치** — https://www.python.org/downloads/
   설치 첫 화면에서 **“Add python.exe to PATH” 체크** 후 설치.
2. **GTK3 런타임 설치 (필수!)** — WeasyPrint가 PDF를 그릴 때 씁니다. 없으면
   `cannot load library 'libgobject…'` 오류로 **PDF 생성이 실패**합니다.
   - 설치 파일: https://github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Installer/releases
   - 최신 `gtk3-runtime-x.x.x-x-x-ts-win64.exe` 를 받아 **기본값으로 설치**.
   - (공식 안내: https://doc.courtbouillon.org/weasyprint/stable/first_steps.html#windows )
3. **poppler 설치 (선택)** — 스캔본 PDF를 OCR로 읽을 때만 필요.
   - https://github.com/oschwartz10612/poppler-windows/releases 에서 zip 받기
   - 원하는 폴더에 풀고, 그 안 `...\Library\bin` 경로를 **시스템 환경변수 PATH에 추가**.
4. **코드 받기** (Git 설치돼 있으면):
   ```bat
   git clone https://github.com/gysung6830-spec/english_data_making.git
   cd english_data_making
   git checkout claude/english-exam-generator-9y3r1x
   ```
   > Git이 없으면 GitHub 페이지 → **Code ▸ Download ZIP** 으로 받아 압축을 풀어도 됩니다.
5. **설치 & 실행 (배치 파일 더블클릭)** — 프로젝트 폴더 안의:
   - `windows_setup.bat` 더블클릭 → 파이썬 패키지 설치 + `.env` 생성
   - 생성된 **`.env`** 를 메모장으로 열어 `ANTHROPIC_API_KEY=sk-ant-...` 입력·저장
   - `windows_run.bat` 더블클릭 → 웹앱 실행 → 브라우저에서 **http://127.0.0.1:5000**
   > 명령프롬프트로 직접 하려면:
   > ```bat
   > python -m venv .venv
   > .venv\Scripts\activate
   > pip install -r requirements.txt
   > copy .env.example .env
   > python webapp.py
   > ```

> **Tip:** 1~3번(파이썬·GTK·poppler)은 그 컴퓨터에서 **최초 1회만** 하면 됩니다.
> 이후에는 `windows_run.bat` 만 더블클릭하면 됩니다.

**② 파이썬 패키지**
```bash
python -m pip install -r requirements.txt
```
> 가상환경 권장:
> ```bash
> python -m venv .venv
> source .venv/bin/activate        # Windows: .venv\Scripts\activate
> pip install -r requirements.txt
> ```

**③ API 키 파일**
```bash
cp .env.example .env
```
`.env` 를 열어 키를 넣습니다:
```
ANTHROPIC_API_KEY=sk-ant-...
```
> 키는 https://console.anthropic.com 에서 발급합니다. 실제 문제 생성에만 필요하며,
> 아래 `--preview` 모드는 키 없이도 디자인을 볼 수 있습니다.

## 2. 실행

### 웹앱 (브라우저에서 사용 — 기본)
```bash
python webapp.py
```
→ 브라우저에서 **http://127.0.0.1:5000** 접속.
지문 붙여넣기 또는 파일(PDF·HWP·사진) 업로드 → 옵션 선택 → **‘시험지 생성’**.

옵션:
```bash
python webapp.py --port 8080          # 포트 변경
python webapp.py --host 0.0.0.0        # 같은 네트워크의 다른 기기에서 접속 허용
python webapp.py --preview            # API 키 없이 데모 지문으로 디자인만 미리보기(비용 0)
```

### 명령줄로 한 번에 (선택)
```bash
python make_exam.py input/파일.pdf --out output/결과.pdf
```

## 3. 자주 나는 오류

| 증상 | 원인·해결 |
|---|---|
| `cannot load library 'libpango…'` / `libgobject…` | 위 **①시스템 라이브러리** 미설치. 해당 OS 명령으로 설치 |
| PDF는 되는데 스캔본이 안 읽힘 | `poppler` 미설치(스캔 PDF Vision OCR용). `poppler-utils`/`brew install poppler` |
| `ANTHROPIC_API_KEY 가 필요합니다` | `.env` 에 키 미입력. 키 없이 보려면 `--preview` |
| 한글/영어가 네모(□)로 나옴 | 폰트는 임베드돼 있어 보통 없음. 그래도 나면 시스템 라이브러리(①) 재설치 |
| `port 5000 … in use` | `--port 8080` 등으로 변경 |

## 4. 이미 만든 결과를 다시 뽑기 (API 비용 없이)

결과 화면에서 **분석 결과(.json)** 를 저장해 두면, 첫 화면 **‘이미 만든 결과 다시 쓰기’** 에
그 파일을 넣어 **머리글(제목)만 바꿔 재출력**할 수 있습니다(재분석·API 호출 없음).
