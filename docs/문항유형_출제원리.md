# 변형문제 출제원리 — 통합 문서

변형문제 **1회(7유형)** 와 **2회(A~G)** 의 *출제 원리 · 우선순위 · 난이도 · 품질보증 · 조판 · 입력정제* 를
한 문서로 모았다. 실제 코드(생성기 프롬프트·`build` 변형기·난이도 레버·검증층·조판기)와 일치한다.

## 파이프라인 한눈에

```
원문 입력(PDF·HWP·사진·붙여넣기)
  → ① 정제(ingest)      영어 본문만 남김(한줄해석·불릿·병합·시간/나이 처리)
  → ② 분석(analyzer)    1회, 정본 문장·핵심어휘·주제·지문종류 추출 (1·2회 공유)
  → ③ 생성(병렬)        1회 7유형 / 2회 A~G 를 정본 지문에서 파생
  → ④ 검증(3층)         구조검증 · 지문종류 적합성 · LLM 자기검증
  → ⑤ 조판(renderer)    2단 PDF(학생/교사/빠른정답/해설 + 확인권장)
```

**두 개의 축이 전체를 지배한다.**
- **정본 지문 공유** — 모든 유형이 *같은 원문 문장*에서 파생한다. 지문을 새로 쓰지 않고, 연결
  텍스트는 원문 그대로 두며 *지정된 부분만* 변형(밑줄·치환·빈칸·배열)한다.
- **패러프레이즈 함정** — 정답은 원문 단어를 그대로 쓰지 않고 **유의어로 재진술**하고, 오답에는
  **지문에 실제 나온 단어를 섞어** "본 것 같은" 착각을 유도한다(→ 원문 단어가 보이는 선지가 함정).

## 0. 전 유형 공통 우선순위 (위에서부터 우선)

1. **정답 유일성(최우선).** 정답은 반드시 하나로 확정되고, 오답 4개는 각각 반박 가능해야 한다.
   난이도를 올려도 *우연 정답·복수 정답*은 금지.
2. **정본 지문 공유.** 모든 유형은 같은 지문 문장(`sentences`)에서 파생한다. 유형마다 지문을
   새로 쓰지 않고, 연결 텍스트는 원문 그대로 두며 *지정된 부분만* 변형(밑줄·치환·빈칸)한다.
3. **원문 보존형 정답.** 어순·영작·빈칸의 정답은 '지문에 실제로 있는 표현' 그대로여야 한다
   (미세 불일치는 유사도 스냅으로 교정, 교정 시 '검토 메모'에 표시).
4. **난이도 레버(상/중/하).** 오답 함정 강도와 정답 패러프레이즈 강도를 함께 조절한다.
5. **정답 위치 분산.** 선지 순서가 자유로운 유형은 정답 번호가 한쪽(주로 ③)에 몰리지 않게 분산.
6. **무인 검수 대비.** 자동 보정 + PDF 맨 끝 '검토 메모'로 사람 점검이 필요한 문항만 표시.

### 대의파악(주제·제목·함축의미) 오답 설계 — 5축 (평가원식)

정답 위치는 언제나 **주제문·반복어구·역접(But/However) 뒤 필자 주장**이며, 이를 **지문 단어가
아닌 다른 말로** 바꿔 표현한다. 오답 4개는 아래 5축에서 고르고, **매력적 오답 1개**(정답과 비슷하나
'한 끗 — 범위 또는 방향'만 어긋남)를 반드시 넣어 변별한다.

1. **범위 비틀기(scope)** — 지문보다 너무 넓게(대주제 확대) 또는 너무 좁게(예시·일부 세부).
2. **방향 반전(polarity)** — 필자 주장과 정반대·왜곡(±어휘, 역접 뒤 주장 뒤집기).
3. **표면 어휘 함정(lexical lure)** — 지문의 눈에 띄는 단어를 그대로 복사, 익숙해 보이나 논점 아님.
4. **근거 없음** — 그럴듯하나 지문에 근거가 없는 내용.
5. **초점 이동** — 소재는 맞지만 필자 논점이 아닌 곁가지.

**추상화 위계: 요지 < 주제 < 제목.** 요지=필자 주장(so what)을 한국어 완결문(당위·평가), 주제=무엇에
관한 글인가를 영어 명사구, 제목=그 주제의 영어 비유 표현(은유·의문형·콜론 부제, 필자 태도 반영).
함축의미=밑줄의 '문맥적' 재진술(축자 뜻 금지, 밑줄의 ± 방향 + 주제를 동시 만족).
(구현: `generators/topic.py`·`title.py`, `gen2._gen_B` 프롬프트에 이 원리를 명시.)

### 출제 순서
- **1회:** 어법 → 어휘 → 주제 → 내용일치 → 순서 배열 → 문장 삽입 → 서술형
- **2회:** 빈칸추론(F) → 함의추론(B) → 요약문 빈칸(E) → 내용일치 개수(G) → 어법·어휘 짝짓기(A) → 어법 오류 판별(C) → 어순 배열(D)

> **배치 선택(웹앱):** *지문별*(기본, 한 지문에 7유형 연속) / *문제유형별*(같은 유형끼리 모음).
> 유형별은 유형마다 번호를 **1번부터** 다시 매기고 빠른정답도 유형별로 묶는다. 어느 쪽이든 위 유형 순서를 따른다.

### 난이도 레버 연동표
| 난이도 | 오답 설계 | 어휘(vocab) 방식 | 내용일치(content) 단계 |
|---|---|---|---|
| 하 | 정반대·무관으로 분명히 어긋나게, 단서 뚜렷 | `original` 원문 단어 노출 | `plain` |
| 중 | 1~2개만 그럴듯(부분일치·유의어 위장) | `synonym` 유의어 | `hard` |
| 상 | 매력적 함정(부분일치·주체 바꿔치기·인과 역전), 정답 패러프레이즈 강화 | `negation` 부정어 삽입 | `hard` |

**핵심 전제:** 난이도는 *지문 내용*이 아니라 *선지(오답·정답)와 단서*로 조절한다. 지문은 그대로 두고
선지를 얼마나 헷갈리게 만드느냐만 바꾼다. (구현: `exam/difficulty.py` 지침 → `Analysis.difficulty_note`
주입 → 모든 생성기 프롬프트에 공통 전달. 어휘 방식·내용일치 단계도 자동 연동.)

**난이도를 가르는 3개 축**

| 축 | 하 | 중 | 상 |
|---|---|---|---|
| 오답 매력도 | 지문과 분명히 어긋남(정반대·무관) | 그럴듯한 오답 1~2 + 명확한 오답 3~4 | 대부분 매력적 함정(부분일치·주체 바꿔치기·인과 역전·지문 단어 미끼) |
| 정답 패러프레이즈 | 원문 단서와 가깝게(축자적으로 잡힘) | 표준 | 유의어·재진술로 강하게 바꿔 축자 대응 회피 |
| 단서 노출 | 연결사·지시어·핵심어를 뚜렷이 남김 | 표준 | 단서를 덜 드러내 추론 부담↑ |

**유형별로 상/하가 어떻게 나타나나**

| 유형 | 하 | 상 |
|---|---|---|
| 순서·삽입 | 연결사·지시어를 살려 단서 뚜렷 | 단서를 덜 드러내 논리 흐름만으로 |
| 주제·요약(E)·빈칸(F) | 정답이 원문 표현에 가까움 | 정답은 강한 유의어 재진술, 오답에 지문 단어 함정 |
| 어휘·어법(C·5번) | 오답이 명확한 오류 | 문맥상 자연스러워 보이는 미세한 오류 |
| 내용일치(6번·G) | 오답이 정반대라 바로 걸림 | 부분일치+한 요소 왜곡, 주체 뒤바꿈, 없던 인과 |
| 함의추론(B) | 축자적 의미와 가까움 | 논지 반영 재진술 vs 축자 오독의 대비 |
| 서술형(7번) | 단서 뚜렷해 복원 쉬움 | 어형·배열 단서를 줄여 부담↑(정답 배열은 원문 고정) |

> **절대 불변 원칙:** 난이도를 올린다는 건 "정답을 애매하게"가 아니라 "오답을 더 정교한 오답으로"
> 만드는 것이다. **상 지침에도 '정답은 하나로 확정, 오답은 각각 반박 가능(복수·우연 정답 금지)'이 못박혀
> 있고**, 아래 품질보증 3층이 세 난이도 모두에서 이를 동일하게 강제한다.

### 품질 보증 — 오류 차단 3층
문항이 나가기 전 세 겹으로 거른다. 걸러내지 못한 것만 마지막에 '확인 권장'으로 사람에게 넘긴다.

1. **구조 검증 (무료·항상).** 코드가 형식을 강제하고, 어긋나면 재생성한다.
   - 순서 최소 4문장·삽입 최소 3문장, 어법 밑줄 2~8개·정답 최소 1개, 정답 번호 범위,
     어순(D)·서술형 배열 토큰이 정답 문장을 **온전히 복원**하는지(단어 누락 차단),
     밑줄 번호를 항상 **읽는 순서**로 재매김, 같은 단어 중복 지정·밑줄 중첩 차단.
   - 자동 보정이 일어난 문항은 '확인 권장'에 표시.
2. **지문 종류 적합성 (무료).** 분석이 판정한 `passage_type`(prose·narrative·notice·chart·letter·dialogue)로
   **부적합 유형**을 '확인 권장'에 표시(문항은 유지).
   - 안내문·도표 → 순서·삽입 / 도표 → 주제·요약·빈칸 / 서사·심경문 → 주제
   - 안내문의 *내용일치*처럼 실제로 적합한 조합은 표시하지 않음(과잉 표시 방지).
3. **LLM 자기검증 (고위험 유형).** 생성 직후 LLM 이 '유일 정답 성립'을 엄격히 재확인.
   - 대상: **1회** 순서·삽입·어법·내용일치 / **2회** B·C·E·F·G
   - **복수정답 · 어법 오탐 · 내용 참/거짓 오판**을 잡아 → 1회 재생성 → 그래도 실패면 '확인 권장(자동검증: 사유)'.
   - 비용 절감: `EXAM_NO_VERIFY=1` 이면 이 층만 끄고 1·2층으로 운영.

> **최종 안전망:** 교사용 PDF 맨 끝 **'확인 권장 문항'** 페이지에 위에서 걸러진 문항이 사유와 함께 모인다
> (학생용 문항에는 배지를 달지 않는다).

## 1회 — 7유형

### ① 순서 배열 `order`
- **발문:** 주어진 글 다음에 이어질 글의 순서로 가장 적절한 것은?
- **출제원리:** 앞 `given_n` 문장을 '주어진 글'로 두고, 나머지를 (A)(B)(C) 세 덩어리로 나눠
  라벨 순서만 섞는다. 정답은 원래 순서를 복원하는 배열.
- **우선순위:** (A)가 1번 덩어리가 되지 않게 섞어 실제 순서를 감춘다 → 연결사·지시어를 근거로
  순서가 **유일하게** 확정되게. `reason`에 그 근거를 한국어로.
- **자동 보정:** `given_n`·`block_sizes`·`display` 가 어긋나면 실패 대신 재분배(→ 검토 메모).

### ② 문장 삽입 `insert`
- **발문:** 글의 흐름으로 보아, 주어진 문장이 들어가기에 가장 적절한 곳은?
- **출제원리:** '내부' 문장 하나(첫·끝 제외)를 빼내 '주어진 문장'으로 만들고, 나머지 흐름에
  ①~⑤ 위치를 표시. 정답은 원래 그 문장이 있던 자리.
- **우선순위:** however/therefore/this/such 등 **연결사·지시어로 위치가 확정**되는 문장을 고른다.
- **자동 보정:** 범위를 벗어난 번호는 내부 위치로 클램프(→ 검토 메모).

### ③ 주제 `topic`
- **발문:** 다음 글의 주제로 가장 적절한 것은? (영어 선지 5개, 제목 아님)
- **출제원리:** 지문은 원본 그대로. 정답은 핵심어휘의 **유의어**로 바꿔 표현(원문 단어 그대로 금지).
- **오답 설계 우선순위:** 무관 2 + 모순 2. 오답에는 '지문에 실제 나온 단어'를 일부 섞어 함정으로.
  정답은 지문 전체를 포괄(과대·과소 일반화 금지).
- **정답 위치 분산 대상.** / 오답 근거가 빈약하면 '검토 메모'.

### ④ 어휘 `vocab`
- **발문:** 밑줄 친 부분 중, 문맥상 낱말의 쓰임이 적절하지 않은 것은?
- **출제원리:** 5개 밑줄 중 정확히 1개만 문맥상 어색(정답). 방식은 난이도에 연동:
  - 하 `original`: 정답만 반의어, 나머지 4개는 **원문 단어 그대로**.
  - 중 `synonym`: 정답=반의어, 나머지=유의어 패러프레이즈.
  - 상 `negation`: 밑줄은 원문 유지, 정답 문장에만 **부정어(no/not/never)** 삽입해 흐름과 모순.
- **우선순위:** 정답 1개만 확실히 어색, 유의어로 바꾼 나머지는 **완전히 자연스럽게**(정답 2개 방지).
- 정답 위치는 밑줄의 읽는 순서로 정해짐(위치 분산 대상 아님).

### ⑤ 어법 `grammar`
- **발문:** 밑줄 친 부분 중, 어법상 틀린 것을 모두 고르시오. **(복수 정답)**
- **출제원리:** 2~8개 밑줄을 읽는 순서대로 배치, 그중 2~4개를 어법상 틀린 형태로.
- **타깃 문법 우선순위:** 수 일치 / 시제 / 태 / 준동사 / 관계사 / 병렬 / 대명사.
- **우선순위:** 틀린 각 번호가 왜 틀렸고 무엇으로 고쳐야 하는지 `reasons`에 명시.

### ⑥ 내용 일치 `content`
- **발문:** 위 글의 내용과 일치하는 것은? (한국어 선지 5개)
- **출제원리:** 지문 원본 그대로. 정답 1개만 일치. 난이도 단계:
  - `plain`(하): 오답을 지문과 명확히 어긋나게(주로 정반대).
  - `hard`(중·상): '뻔한 정반대'를 피하고 아래 4함정을 **각각 하나씩**.
- **오답 4함정(우선순위대로 골고루):**
  1. 부분 일치 + 한 요소만 왜곡(숫자·범위·조건)
  2. 주체 바꿔치기(행위자/대상만 맞바꿈)
  3. 인과 날조·역전(없던 because 삽입 / 원인·결과 뒤집기)
  4. 미언급인데 그럴듯(모순 아님, 단지 지문에 없음)
- 정답은 유의어로 위장, 오답엔 원문 단어 노출로 함정. **정답 위치 분산 대상.**

### ⑦ 서술형 `short_answer` (세 소문항)
- **발문:** 다음 글을 읽고 물음에 답하시오.
- **출제원리(소문항별):**
  1. **독해 이해 확인** — 특정 어구·사례의 뜻을 묻고, 답은 **한국어**로.
  2. **문법 문장 영작(낱개 배열)** — 지문 문장 하나를 골라 낱개 단어로 뒤섞고, 동사는 **원형**으로
     제시(원형 단어는 `cues`). 정답은 그 지문 문장 **글자 그대로**(원래 배열).
  3. **영어 요약문 빈칸(어형변화)** — 지문을 한 문장 요약, (A)(B) 빈칸에 들어갈 올바른 형태.
- **우선순위:** (2)의 정답은 반드시 지문 실제 문장과 일치(스냅 교정, 교정 시 검토 메모).

## 2회 — A~G

### A. 어법·어휘 짝짓기
- **발문:** 밑줄 친 ⓐ~ⓔ 중, 어법상 또는 문맥상 낱말의 쓰임이 적절하지 않은 것끼리 짝지어진 것은?
- **출제원리:** 밑줄 5개(ⓐ~ⓔ) 중 **정확히 2개만 오답** — 1개는 어법 오류, 1개는 반의어(문맥상 반대말).
  나머지 3개는 원문 그대로. 선지 5개는 두 밑줄의 짝(예 'ⓐ, ⓒ').
- **정답 위치 분산 대상.**

### B. 함의추론
- **발문:** 밑줄 친 부분이 다음 글에서 의미하는 바로 가장 적절한 것은?
- **출제원리:** 비유·맥락의존 어구 하나를 밑줄(지문에 그대로 있는 표현), 영어 선지 5개.
  정답=글 전체 논지를 반영한 재진술, 오답=축자적 오독 또는 논지 위배.
- **우선순위:** 밑줄 어구는 따옴표·대시 차이를 무시하고 지문 실제 표기로 교정. **정답 위치 분산 대상.**

### C. 어법 오류 판별
- **발문:** 밑줄 친 부분 중, 어법상 틀린 것을 모두 고르시오. **(복수 정답)**
- **출제원리:** 1회 ⑤ 어법 생성기를 그대로 재사용(타깃 문법·복수 정답 동일).
- 정답 위치는 읽는 순서로 정해짐(분산 대상 아님).

### D. 어순 배열
- **발문:** 다음 <보기>의 단어를 모두 배열하여 글의 내용과 일치하는 문장을 완성하시오.
- **출제원리:** 지문 문장 하나를 골라 낱개 단어로 뒤섞어 `tokens`로(구 묶음 금지). 동사는 원형+`cues`.
  정답은 그 지문 문장 **글자 그대로**(원래 배열).
- **우선순위:** 정답은 지문 실제 문장과 일치(스냅 교정, 교정 시 검토 메모).

### E. 요약문 빈칸
- **발문:** 다음 글의 요약문 빈칸 (A), (B)에 들어갈 말로 가장 적절한 것은?
- **출제원리:** 지문 한 문장 요약에서 핵심어 2곳을 (A)(B)로 비우고, 단어쌍(a,b) 선지 5개.
  정답 쌍은 (A)(B) 둘 다 논지에 맞되 **유의어(패러프레이즈)**.
- **오답 설계 우선순위:** (A)만 맞음 / (B)만 맞음 / 둘 다 어긋남을 골고루, 일부엔 지문 단어로 함정.
  (A)(B) 둘 다 맞는 쌍은 **정답 하나뿐**(우연히 둘 다 맞는 오답 금지). **정답 위치 분산 대상.**

### F. 빈칸추론
- **발문:** 다음 빈칸에 들어갈 말로 가장 적절한 것은?
- **출제원리:** 지문 전체를 보여주되 글의 **핵심(주제) 어구** 하나를 빈칸으로. 영어 선지 5개.
  정답은 원문 어구의 **유의어 패러프레이즈**(원문 그대로 금지, 뜻 어긋남 금지).
- **우선순위:** 빈칸 어구는 지문에 **정확히 한 번만** 등장해야 함(중복이면 오답 유출). 오답 4개는 각각
  '확실히' 모순·무관. **정답 위치 분산 대상.**

### G. 내용일치 개수
- **발문:** 다음 글의 내용과 일치하는 것의 개수는?
- **출제원리:** 지문을 패러프레이즈한 한국어 진술 5개, 각 일치 여부(bool). 정답=일치 개수(1~5).
- **우선순위:** 일치 개수는 1~5(0개 불가). 불일치는 주체·정도·인과를 뒤집거나 없는 내용으로.
  정답은 '개수'라 위치 분산 대상 아님.

## 3회 — 대의파악 집중 (주제 1 + 제목·내용일치·함축의미 각 3 = 지문당 10문항)

한 지문에서 **주제 1문항 + 제목·내용일치·함축의미 각 3문항 = 지문당 10문항**을 내는
이해·요지 집중 세트. (주제는 정답 개념이 하나뿐이라 1문항으로 고정.)
같은 유형을 3번 낼 때는 겹치지 않도록 **변형마다 다른 '구조적 각도'**(내용일치=앞/중/뒤 사실,
함축=전/중/후반 밑줄, 제목=명사구/의문형/콜론형)를 배정하고 **정답 위치도 분산**한다.
유형별 문항 수는 `set3.py`의 `_BASES` 마지막 값으로 조절한다.

| 유형 | 발문 | 원리 |
|---|---|---|
| 주제 | 다음 글의 주제로 가장 적절한 것은? | 1회 ③과 동일(핵심어 유의어 재진술, 오답에 지문 단어 함정) |
| 제목 | 다음 글의 제목으로 가장 적절한 것은? | 글 전체를 아우르는 **간결·함축적 제목**(주제문보다 짧게), 정답=유의어 |
| 내용 일치 | 위 글의 내용과 일치하는 것은? | 1회 ⑥과 동일(정답 1개, 오답 4함정) |
| 함축의미 | 밑줄 친 부분이 의미하는 바로 가장 적절한 것은? | 2회 B(함의추론) 재사용 |

- 구현: `set3.py`(유형키 `topic_1…imply_3`) · `gen3.py`(변형별 생성) · `demo3.py`(미리보기).
- 유형별 배치를 쓰면 `[주제] 1 → [제목] 1·2·3 → [내용 일치] 1·2·3 → [함축의미] 1·2·3` 로 유형마다 번호가 1부터.
- 자기검증은 **내용일치·함축의미**에 적용(base 로 정규화).

## 정답 위치 분산 대상 요약
| 분산 O (선지 순서 자유) | 분산 X (위치가 구조적으로 결정) |
|---|---|
| 주제 · 내용일치 · A · B · E · F | 순서 · 삽입 · 어휘 · 어법 · C · D · G |

- **분산 O:** 선지를 재배열해 정답을 목표 위치로 옮김(정오·오답 근거 불변). 지문·시험지마다 시작
  위치를 달리해 '늘 같은 번호'를 방지.
- **분산 X:** 정답 위치가 읽는 순서(어휘·어법·삽입·C)·배열(순서·D)·개수(G)로 이미 내용에 따라 달라짐.

## 조판 · 배치 · 폰트
- **배치:** 지문별(기본) / 문제유형별 — 웹앱에서 선택. 유형별은 유형마다 번호를 1번부터, 빠른정답도 유형 소제목으로 묶음.
- **번호:** 지문별은 문서 전체 연속(지문1: 1~7, 지문2: 8~14…). 원본 PDF에 문항번호가 있으면 지문 라벨에 그대로 표기([27번]…), 없으면 '[지문 i]'. 웹앱 '시작 문항번호'로 수동 지정도 가능(비우면 원본/순번).
- **폰트:** 영어(라틴)=세리프(**Liberation Serif**) · 한글=**나눔스퀘어라운드**. 둘 다 woff2 base64 임베드라 폰트 미설치 환경에서도 동일 렌더.
- **구성 선택:** 학생용 / 교사용(해설·정답 볼드) / 빠른정답 / 해설지 — 원하는 것만 골라 한 PDF 합본. 세트(1·2회)×난이도(하·중·상)도 합본 가능.

## 입력 정제(전처리) 원리
EBS·모의고사 원문을 넣으면 **영어 본문만** 남기고 잡음을 제거한다(사례 모음: `변형문제_오류대응.md`).
- **한줄해석(한글 번역) 제거:** 한글 우세 줄 통째 제거 + 번역 줄에 남는 영어 고유명사 잔재(윗줄 원문 단어의 부분집합)까지 제거 + '번역 안 된 제목' 중복 제거.
- **안내문 불릿(`*` `※` `•`):** 목록 표시일 뿐이므로 문장 경계로 치환해 본문에서 없앰.
- **지문 병합 방지:** NUL(`\x00`) 등 제어문자 정리 + `[고N] … N번:` 헤더로 지문 경계를 나눠 번호 보존(여러 지문이 하나로 합쳐지던 버그 차단).
- **오인 삭제 방지:** `10:00.`(시간)·`5-12`(나이·범위)의 숫자를 '문장 앞 번호'로 오인해 지우지 않음.
- **채택 기준:** 영문 120자 미만(도표 수치·'윗글 참조'만 있는 조각 등)은 지문에서 제외.

## 부록 A. 출제상 오류 가능성 & 대응 (현행)

오류를 두 종류로 나눈다.
- **A. 구조·조판 오류** — 프로그램이 깨지거나 형식이 어긋남 → **대부분 방어됨**(재시도·보정·에러).
- **B. 내용 타당성 오류** — 형식은 멀쩡한데 정답이 둘이거나 틀리거나 모호 → **품질보증 2·3층으로 대응**.

### A. 구조·조판 오류 (방어 상태)
| 오류 | 대응 |
|------|------|
| 순서 덩어리 수·given_n 오산 | `make_order` 자동 재분배/클램프(→확인권장) |
| 삽입 위치 번호 범위 초과 | `make_insert` 내부문장 클램프(→확인권장) |
| 밑줄 단어 대소문자/철자 불일치 | 단어경계→대소문자무시→부분일치 폴백 |
| 밑줄 중첩·같은 단어 중복 지정 | 플레이스홀더 치환으로 차단, 중복 시 실패→재시도 |
| 어순(D)·서술형 배열 토큰 누락 | 정답 문장 복원 불가 시 실패→재생성 |
| G 일치 개수 0개/선지 불일치 | 1~5개 강제, 선지 동적 생성 |
| 빈칸(F) 어구 다중 출현 | 지문 내 유일성 검사→실패 시 재시도 |
| 약어(Dr./U.S.)에서 문장 오분리 | 약어 보호 후 분리 |
| 지문 병합·머리글/시간·나이 오삭제 | ingest 정제(§ 입력 정제 원리) |
| 유형 생성 실패 | 유형별 2회 재시도 후 명확한 에러 |

### B. 내용 타당성 오류 (유형별 리스크 → 현행 대응)
> 공통 리스크: 정답=유의어로 바꾸는데 오답도 우연히 맞거나(복수정답), 유의어가 문맥상 부정확(정답오류).

| 유형 | 대표 오류 | 현행 대응 |
|---|---|---|
| 순서·삽입 | 단서 약해 두 순서/두 위치 다 성립 | 지시어·연결사 문장 선택(프롬프트) + **LLM 자기검증(유일성)** |
| 주제·내용일치·B·G | 오답이 부분적으로 참 / 정답 과대일반화 | 선지별 근거 + **LLM 자기검증(복수정답·오독)** |
| 어휘 | 유의어 교체로 오답이 2개 / 부정어 넣어도 말 됨 | 문맥 유지·모순 확인(프롬프트) |
| 어법·A·C | '정상' 밑줄이 애매히 틀림 / '틀린' 게 허용 용법 | 서로 다른 문법 포인트 배정 + **LLM 자기검증** *(규칙기반 품사태깅은 향후 과제)* |
| 서술형(2)·D | 정답 외 다른 배열도 성립 | 짧고 어순 고정 문장 선택 + 토큰 완비 검증 |
| 서술형(3)·E | 어형 둘 다 가능 / E 오답쌍이 우연히 양쪽 맞음 | 어형 확정 신호 + E 정답쌍 유일성 + **LLM 자기검증(E)** |
| 빈칸 F | 주제 아닌 곳을 뚫음 / 정답 부정확 | 핵심어구 위치+유일 등장 + **LLM 자기검증(F)** |

### 남은 과제(정직하게)
- **어법·어순의 규칙기반화**(품사태깅 spaCy/nltk)로 문법 오판을 결정적으로 제거 — 미구현.
- LLM 자기검증도 미묘한 복수정답은 놓칠 수 있음 → **최종 안전망은 '확인 권장' 페이지의 사람 검수**.
