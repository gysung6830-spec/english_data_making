# 네이버 검색 유입 + 과외 문의 전환 전략 (진주 영어과외)

> 목표: `진주영어과외` 검색 시 상단 노출 + 실제 연락 오게 만들기
> 조건: 현직 학원 강사(신분 노출 최소) · 사진 최소 · 성적 실적 없음

---

## 0. 먼저 알아야 할 현실

**글 하나로 `진주영어과외` 상단에 가는 방법은 없습니다.**

네이버는 두 가지를 봅니다.
- **C-Rank** — 이 블로그가 "영어교육"이라는 주제를 얼마나 꾸준히·깊게 다뤄왔는가 (블로그 단위 누적 점수)
- **D.I.A.+** — 이 글이 검색한 사람의 의도를 실제로 해결해 주는가 (글 단위 품질)

즉 **신규 블로그가 대형 키워드를 바로 먹는 건 불가능**하고,
**작은 키워드부터 상단을 잡아 나가면서 블로그 지수를 쌓는 것**이 유일한 길입니다.

현실적인 타임라인:
| 시점 | 기대할 수 있는 것 |
|---|---|
| 1~2주 | 롱테일 키워드(월 조회 100 미만) 상단 노출 시작 |
| 3~6주 | 중간 키워드(`진주 고등영어과외` 등) 1페이지 진입 |
| 2~3개월 | `진주영어과외` 1페이지 도전 가능 |

> 그래서 아래 **4주 발행 캘린더**가 홍보 글 한 편보다 중요합니다.

## 1. 키워드 전략 — 큰 것부터 노리지 마세요

### 공략 순서

| 단계 | 키워드 예시 | 경쟁 | 언제 |
|---|---|---|---|
| 1단계 (지금 바로) | `진주 고1 영어 내신`, `고2 영어 서술형 대비`, `영어 직독직해 하는법`, `수능영어 문장삽입 푸는법` | 낮음 | 1~2주차 |
| 2단계 | `진주 고등영어과외`, `진주 수능영어 과외`, `진주 영어 내신학원` | 중간 | 3~6주차 |
| 3단계 | `진주영어과외`, `진주과외` | 높음 | 2개월 이후 |

### 키워드 조사 방법 (무료)
1. **네이버 검색광고** (searchad.naver.com) → 도구 → 키워드 도구
   → 키워드 입력 시 **월간 검색수**와 **경쟁 정도**가 나옵니다.
2. 기준: **월 검색수 100~1,000 / 경쟁 낮음** 인 키워드부터 잡으세요.
3. 네이버에 그 키워드를 직접 검색해서 **1페이지 글이 몇 개나 되는지, 최근 글인지** 확인하세요.
   → 1페이지에 오래된 글이나 광고성 글만 있으면 **뚫리는 키워드**입니다.

### 지역 키워드 조합 만들기
`진주` + `[학교명 / 동네 / 학년 / 과목 / 목적]` 형태로 조합합니다.

- 동네: `평거동` `초전동` `충무공동` `하대동` `상평동` `가좌동` `신안동` `혁신도시`
  → 예: `평거동 영어과외`, `초전동 고등영어`, `진주혁신도시 영어과외`
- 학년: `진주 고1 영어`, `진주 고2 영어내신`, `진주 고3 수능영어`
- 목적: `진주 영어 내신대비`, `진주 영어 서술형`, `진주 모의고사 영어`

> ⚠️ **학교명 키워드**(`○○고 영어 내신` 등)는 유입이 아주 잘 되지만, 학원 재직 중이시니 신중하세요.
> 학교명을 특정하면 동료·원장이 글을 찾아낼 가능성이 올라갑니다.
> 안전하게 가려면 학교명 대신 **동네명 + 학년**으로 조합하시길 권합니다.

## 2. 제목 공식

```
[지역 키워드] + [대상] + | + [구체적 이득 or 궁금증]
```

**좋은 예**
- `진주 고등영어과외 | 학교 시험범위 지문 분석지, 먼저 보여드립니다`
- `진주 고1 영어 내신, 3월 모의고사 4등급이면 뭐부터 해야 할까`
- `영어 직독직해 하는 법 — 문장이 안 끊기는 이유 3가지 (진주 고등영어)`
- `수능영어 문장삽입, 지시어만 보면 답이 보입니다`
- `평거동 고등영어과외 | 소수정예 4명, 자료 직접 만듭니다`

**나쁜 예**
- `진주영어과외 진주영어과외 최고의 진주영어과외` ← 키워드 반복 = 어뷰징 판정
- `영어 잘하는 법` ← 너무 넓고 경쟁 과다
- `안녕하세요 첫 글입니다` ← 검색 키워드 0

**규칙**
- 제목은 **25~40자**
- 핵심 키워드는 **제목 맨 앞쪽**에 1번만
- 숫자·질문형이 클릭률을 올립니다 (`3가지`, `~할까`, `~하는 법`)

## 3. 본문 작성 체크리스트 (매 글마다)

- [ ] **글자 수 1,500자 이상** (2,000자 이상 권장)
- [ ] **첫 3줄 안에 핵심 키워드** 자연스럽게 등장 (검색 결과 미리보기에 노출됨)
- [ ] 핵심 키워드를 본문 전체에 **5~8회** 자연스럽게 반복 (그 이상은 어뷰징)
- [ ] **소제목 5개 이상** (네이버 에디터의 '제목' 스타일 적용 — 구조가 있는 글로 인식됨)
- [ ] **이미지 5장 이상** — 분석지·어휘리스트·시험지 캡처로 채우기
- [ ] 이미지마다 **캡션(설명 글)** 달기
- [ ] **표를 1개 이상** 사용 (체류시간·품질 점수에 유리)
- [ ] 글 마지막에 **댓글 유도 문장** 배치
- [ ] **태그 10개 이하** (그 이상은 감점)
- [ ] 다른 내 글로 가는 **링크 1~2개** (체류시간 상승)

### 체류시간을 늘리는 장치
검색 유입보다 **체류시간**이 순위에 더 큰 영향을 줍니다.
- 글 중간에 "직접 풀어보세요" 문제 1~2개 삽입 → 답은 글 아래쪽에
- 자료 PDF 캡처를 크게 넣기 (스크롤 시간 증가)
- "다음 글에서 이어집니다" 로 시리즈 연결

## 4. 4주 발행 캘린더 (주 3회 · 총 12편)

**핵심 원칙: 홍보 글은 12편 중 3편만.** 나머지 9편은 **정보 글**입니다.
정보 글이 검색 유입을 만들고, 홍보 글이 전환을 만듭니다. 홍보 글만 쓰면 지수가 안 오릅니다.

| 주차 | # | 제목 | 유형 | 타깃 키워드 |
|---|---|---|---|---|
| 1주 | 1 | 진주 고등영어과외 \| 학교 시험범위 지문 분석지, 먼저 보여드립니다 | **홍보** | 진주 고등영어과외 |
| 1주 | 2 | 영어 직독직해 하는 법 — 문장이 안 끊기는 진짜 이유 3가지 | 정보 | 영어 직독직해 하는법 |
| 1주 | 3 | 고1 3월 모의고사 4등급, 단어부터 외우면 안 되는 이유 | 정보 | 고1 모의고사 영어 |
| 2주 | 4 | 고등 영어 서술형, 시험 2주 전에 시작하면 늦습니다 | 정보 | 고등영어 서술형 대비 |
| 2주 | 5 | 수능영어 문장삽입(38·39번), 지시어만 보면 답이 보입니다 | 정보 | 수능영어 문장삽입 |
| 2주 | 6 | 진주 고2 영어 내신, 4주 대비 계획표 그대로 공개합니다 | **홍보** | 진주 고2 영어 |
| 3주 | 7 | 영어 단어 외워도 해석이 안 되는 학생들의 공통점 | 정보 | 영어 해석 안될때 |
| 3주 | 8 | 수능영어 빈칸(31~34번) — 주제문 찾는 3단계 | 정보 | 수능영어 빈칸 |
| 3주 | 9 | 고3 6월 모의고사 이후, 남은 기간 영어 로드맵 | 정보 | 고3 영어 공부법 |
| 4주 | 10 | 영어 어휘 시험지 무료 나눔 (지문 주시면 만들어 드립니다) | **홍보** | 영어 어휘 시험지 |
| 4주 | 11 | 글의 논리 구조로 푸는 순서 배열(36·37번) | 정보 | 수능영어 순서 |
| 4주 | 12 | 진주 평거동/혁신도시 고등영어 소수정예 모집 안내 | **홍보** | 평거동 영어과외 |

> 정보 글 하나하나가 **자료 캡처를 넣을 자리**입니다. 예를 들어 2번 글에서는 직독직해 2단 표를 그대로 보여주면 됩니다.
> 이게 사진 없이도 글이 풍성해지는 방법이고, 동시에 실력 증명입니다.

**발행 리듬**
- 주 3회, **같은 요일·같은 시간대**에 발행 (예: 월·수·금 오후 9시)
- 학부모가 블로그를 보는 시간대는 **오후 9시~11시**
- 한 번에 몰아 쓰고 예약 발행하세요

## 5. 문의를 실제로 오게 만드는 장치

검색 유입이 있어도 연락이 안 오는 이유는 **문의 허들이 높아서**입니다.
"과외 상담 문의" 는 부담스럽고, "무료 자료 받기" 는 부담이 없습니다.

### 허들 낮추기 3단계

| 단계 | 요청 | 부담 |
|---|---|---|
| 1단계 | "시험범위 지문 1개 보내주시면 분석 자료 무료로 만들어 드립니다" | 매우 낮음 |
| 2단계 | (자료 받은 뒤) "도움 되셨으면 10분 통화로 아이 상태 진단해 드릴게요" | 낮음 |
| 3단계 | "진단 테스트 해보고 결정하셔도 됩니다" | 중간 |

**핵심은 1단계입니다.** 이 도구가 있으니 자료 제작 비용이 거의 0이고,
학부모 입장에서는 **공짜로 받아보고 실력을 직접 확인**할 수 있습니다. 실적 없는 초기에 가장 강력한 카드입니다.

### CTA 배치 위치
- 글 **중간**(자료 소개 직후) 1회 — 가장 반응 좋은 위치
- 글 **끝** 1회
- 그 이상 넣으면 광고성 글로 보입니다

### 문의 채널 (신분 노출 최소화)
| 채널 | 노출 위험 | 비고 |
|---|---|---|
| **카카오 오픈채팅** | 낮음 | 익명 가능. **1순위 권장** |
| **블로그 비밀 댓글** | 낮음 | 전화번호 안 남겨도 됨. 진입 장벽 최저 |
| 네이버 폼 / 구글 폼 | 낮음 | 학년·학교·고민 미리 받아 상담 효율 ↑ |
| 전화번호 직접 노출 | **높음** | 초기에는 쓰지 마세요 |

> 오픈채팅 링크는 **프로필·모든 글 하단·글 중간** 세 곳에 두세요.

### 응답 속도
문의는 **1시간 안에** 답하세요. 학부모는 보통 3~4곳에 동시에 문의합니다. 먼저 답한 쪽이 잡습니다.

## 6. 블로그 세팅 (한 번만 하면 됨)

- **블로그 주제**: 관리 → 기본 설정 → 주제를 **`교육·학문`** 으로 지정 (C-Rank의 주제 일치도에 영향)
- **블로그명**: `진주 고등영어 공부법` 처럼 **키워드 포함** (예: `진주 고등영어 노트`)
- **별명**: 실명 X. 필명 사용 (예: `진주영어쌤`)
- **프로필 사진**: 얼굴 대신 **분석지 캡처 또는 단색 이미지**
- **소개글**: `진주에서 고등 영어를 가르칩니다. 지문 분석 자료를 직접 만들어 공유합니다.` (30자 내외 + 키워드)
- **모먼트/이웃**: 같은 교육 분야 블로그와 이웃 추가 → 초기 유입에 도움
- **네이버 지식iN**: 영어 학습 질문에 성실히 답변하면서 블로그 유입 (하루 2~3개, 링크 도배 금지)

## 7. 절대 하면 안 되는 것 (저품질 = 검색에서 사라짐)

- ❌ 제목·본문에 키워드 억지 반복 (`진주영어과외` 20번)
- ❌ 다른 블로그 글 복붙 (유사문서 판정 → 즉시 누락)
- ❌ 하루에 5편 이상 몰아서 발행
- ❌ 없는 후기·성적 지어내기 (표시광고법 위반 + 나중에 발각 시 치명적)
- ❌ 서로이웃 품앗이 댓글 대량 작성
- ❌ 같은 글을 제목만 바꿔 재발행
- ❌ 외부 상업 링크 다량 삽입

## 8. 첫 2주 실행 순서

1. **블로그 세팅** (위 6번) — 30분
2. 이 도구로 **샘플 지문 3~4개 분석 자료 생성** → 캡처 이미지 10장 확보 — 1시간
   ```bash
   python run.py --mock      # API 키 없이 디자인만 볼 때
   python run.py             # 실제 지문으로 자료 생성
   ```
3. **키워드 도구**에서 롱테일 키워드 10개 선정 — 30분
4. **1주차 글 3편** 미리 작성 → 예약 발행
5. **오픈채팅방 개설** + 링크 확보
6. 발행 후 **네이버 검색광고 → 키워드 순위 확인** 주 1회 체크

> 2주 지나도 검색 노출이 하나도 없으면, 키워드가 너무 큰 것입니다. 더 작은 롱테일로 내리세요.
