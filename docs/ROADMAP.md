# 개원까지 자료 구축 로드맵

목표: 개원일에 **레벨별로 최소 1년치 자료가 갖춰진 상태**로 문을 여는 것.

자료가 없는 상태로 열면 개원 첫 6개월을 자료 만드는 데 다 씁니다.
그 6개월은 학생을 받고 수업의 질로 승부해야 하는 시기입니다.
지금 쌓아 두는 이유가 여기에 있습니다.

---

## 0. 총량과 속도

| 항목 | 숫자 |
|---|---|
| 전체 목표 | **864편** (`curriculum levels` 참고) |
| 개원 시 최소 필요분 | 전체의 50% ≈ **430편** |
| 주 5편 페이스 | 연 260편 → **약 20개월**에 430편 |
| 주 3편 페이스 | 연 156편 → **약 33개월**에 430편 |

> 주 3편이면 하루 30분씩 주 3일입니다. 몇 년이 있다면 충분히 되는 속도입니다.
> 중요한 건 속도가 아니라 **끊기지 않는 것**입니다.

현재 진행률은 언제든 아래로 확인합니다.

```bash
python manage.py status
python manage.py curriculum gap
```

## 1단계 · D-36~24개월 — 뼈대 만들기

**이 시기의 목표는 물량이 아니라 "형식 확정"입니다.**

- [ ] 개원할 지역·타깃 학년을 정한다 → 레벨 우선순위가 여기서 결정됨
- [ ] 타깃 학년 레벨부터 자료를 만든다 (전 레벨을 동시에 하지 말 것)
- [ ] 지문 20~30편을 실제로 만들어 보고 **분석지 양식을 확정**한다
      (양식이 바뀌면 이전 자료를 다시 뽑아야 하므로, 초반에 확정할수록 이득)
- [ ] `config.yaml` 의 `design.footer_note` · `design.brand` 를 정한다
- [ ] 태그 체계를 확정한다 (주제 태그 / 유형 태그 / 난도 태그)

**산출물 기준: 타깃 레벨 1개에 60~80편.**

> 양식은 `python run.py --mock` 으로 API 비용 없이 계속 미리볼 수 있습니다.

---

## 2단계 · D-24~12개월 — 물량 쌓기

**형식이 확정됐으니 이제 배치로 밀어 넣는 시기입니다.**

- [ ] 주력 레벨 2~3개를 목표치의 70%까지 채운다
- [ ] `python run.py --batch` 로 대량 처리 (Batch API 로 비용 절반)
- [ ] 분기마다 `curriculum gap --level` 로 **유형 편중**을 점검한다
      (모의고사만 잔뜩 있고 교과서 지문이 없는 상태를 막기 위함)
- [ ] `custom`(자체 제작) 지문 비중을 20% 이상으로 끌어올린다 — 저작권 안전판
- [ ] 자료 검수 루틴을 만든다: `draft` 로 들어온 것만 주 1회 몰아서 `ready` 로 승격

**산출물 기준: 누적 250~350편.**

## 3단계 · D-12~6개월 — 수업 형태로 조립하기

**낱개 지문에서 "수업"으로 넘어가는 단계입니다.**

- [ ] 레벨별 16주 진도표를 실제 자료 ID 와 매칭해 본다
      (`curriculum plan` 의 주차별 지문 칸을 실제 ID 로 채워 보기)
- [ ] 4주 단위 누적 복습 자료를 미리 만들어 본다 → `pack review`
- [ ] 시범 수업(지인 자녀 등)을 몇 회 해 보고 `notes` 필드에 피드백을 남긴다
- [ ] 학부모 상담 자료 양식을 정한다 → `student report` 출력을 기반으로
- [ ] 교습소 등록 요건을 확인한다 (아래 5번)

**산출물 기준: 누적 400~500편 + 레벨별 진도표 완성.**

## 4단계 · D-6~0개월 — 개원 준비

- [ ] 반 편성 시나리오를 `school/classes.yaml` 로 미리 짜 본다
- [ ] 첫 학기 16주 수업 자료를 **전부 인쇄 가능한 상태**로 준비
- [ ] 시간표·정원·수강료 확정
- [ ] `library/` 를 git 원격 저장소에 백업 (컴퓨터 고장 대비)
- [ ] 웹앱을 배포해 태블릿·폰에서도 자료를 뽑을 수 있게 (`DEPLOY.md`)

## 5. 개원 전 반드시 확인할 행정 사항

이 저장소가 대신해 줄 수 없는 부분입니다. 시점이 가까워지면 확인하세요.

- **교습소 vs 학원**: 교습소는 강사 1인·동시 교습 인원 제한이 있고,
  학원은 시설·면적 기준이 다릅니다. 어느 쪽으로 등록할지에 따라
  반 정원(`classes.yaml`)과 시간표 설계가 완전히 달라집니다.
- **동시 교습 인원 상한**: 지자체 교육지원청 기준을 확인하세요.
  이 값이 정해져야 반 개수와 필요한 자료 물량이 확정됩니다.
- **시설 기준**: 면적·소방·위생 요건
- **교습비 신고**: 시·도 교육청에 신고한 금액 초과 징수 불가
- **저작권**: `docs/LIBRARY.md` 6번 참고
- **개인정보**: 학생 정보는 `school/` 에만 두고 git 에 올리지 않습니다
  (`.gitignore` 에 이미 걸려 있음). 실명 대신 학생코드를 쓰세요.

## 6. 매달 5분 점검

```bash
python manage.py status
```

이 한 줄이 보여 주는 것:

- 지금까지 몇 편을 모았고, 목표 대비 몇 %인가
- **어느 레벨이 비어 있는가** ← 다음 달에 뭘 만들지가 여기서 나옵니다
- 지금 자료로 몇 주 수업이 가능한가 (`커버 주수`)

숫자가 안 움직인 달이 두 번 연속이면, 목표를 낮추더라도 페이스를 되살리세요.
