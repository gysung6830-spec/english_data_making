# 커리큘럼 체계

레벨 정의는 `curriculum/levels.yaml`, 수업 운영 규격은 `curriculum/syllabus.yaml`
한 곳에만 있습니다. 진도표·자료 목표치는 전부 이 두 파일에서 **계산되어 나옵니다**.
표를 손으로 만들지 마세요 — 손으로 만든 표는 6개월 뒤 현실과 어긋납니다.

```bash
python manage.py curriculum levels        # 레벨 체계 한눈에
python manage.py curriculum plan H1       # H1 의 16주 진도표
python manage.py curriculum gap           # 레벨별 자료 부족분
python manage.py curriculum gap --level H1  # H1 안에서 유형별 부족분
```

---

## 1. 레벨 9단계

| 레벨 | 이름 | 대상 | 누적 목표 어휘 | 지문 길이 | 목표 자료 |
|---|---|---|---|---|---|
| E1 | 초등 기초 | 초3~4 | 800 | 60~110단어 | 64편 |
| E2 | 초등 발전 | 초5 | 1,200 | 90~140단어 | 64편 |
| E3 | 예비중 | 초6 | 1,600 | 110~170단어 | 64편 |
| M1 | 중1 | 중1 | 2,000 | 130~190단어 | 80편 |
| M2 | 중2 | 중2 | 2,600 | 150~210단어 | 80편 |
| M3 | 중3·예비고 | 중3 | 3,200 | 170~240단어 | 96편 |
| H1 | 고1 | 고1 | 4,000 | 180~260단어 | 128편 |
| H2 | 고2 | 고2 | 5,000 | 200~280단어 | 128편 |
| H3 | 고3·수능 | 고3·N수 | 6,000 | 200~300단어 | 160편 |

**전체 목표: 864편.** 이 숫자가 자료 구축 로드맵의 기준선입니다.

---

## 2. 목표 자료 수는 어떻게 나온 숫자인가

```
한 학기 16주 × 주 2편 = 32편  →  1년(2학기) = 64편
```

- E1~E3: 64편 = 딱 1년치. 초등은 회전이 빠르므로 최소치.
- M1~M2: 80편 — 내신 대비로 같은 교과서 지문을 반복해야 해서 여유분 필요.
- M3: 96편 — 교과서 + 모의고사 진입으로 종류가 늘어남.
- H1~H2: 128편 = 2년치. 내신·모의고사를 병행하고, 반이 여러 개면 같은 자료를
  돌려쓰기 어렵기 때문입니다.
- H3: 160편 — 수능 대비는 물량 싸움입니다.

레벨별 `material_target` 을 고치면 갭 리포트가 즉시 따라옵니다.

---

## 3. 유형 비중(source_mix)

레벨마다 "어디서 지문을 가져올지"의 비중이 정해져 있습니다.
예를 들어 H1 은 내신 30% · 모의고사 35% · 교과서 15% · EBS 10% · 시중교재 10%.

이 비중 × 목표 자료 수 = **유형별 목표치**이고,
`curriculum gap --level H1` 이 유형별로 몇 편이 비었는지 알려줍니다.

초등·중등에서 `custom`(자체 제작) 비중을 높게 잡아 둔 이유는 두 가지입니다.
저작권에서 자유롭고, 우리 교습소만의 색이 거기서 나오기 때문입니다.

---

## 4. 주차 진도는 문법 시퀀스에서 나온다

각 레벨에는 16개의 문법 주제가 순서대로 들어 있습니다(`grammar_sequence`).
1주에 1주제, 주 2회 수업, 회차당 지문 1편 — 이것이 기본 리듬입니다.

여기에 `syllabus.yaml` 의 평가 주기가 얹힙니다.

| 주기 | 무엇 |
|---|---|
| 매주 | 어휘 테스트 (직전 2지문) |
| 4주 | 누적 어휘 시험 (직전 8지문) + 월간 학습 리포트 |
| 8주 | 중간 점검 테스트 |
| 16주 | 학기 총괄 평가 + 학기 상담 |

`python manage.py curriculum plan H1` 을 돌리면 이 모든 게 합쳐진 16주 표가 나옵니다.

## 5. 한 회차(90분) 구성

| 분 | 블록 | 쓰는 자료 |
|---|---|---|
| 10 | 어휘 확인 테스트 | 지난 회차 어휘 시험지 |
| 15 | 어휘·배경 도입 | 핵심 어휘 리스트 |
| 30 | 지문 정독 · 직독직해 | 분석지 ②번 |
| 20 | 문법 포인트 강의 | 분석지 ③번 + 주차 문법 주제 |
| 10 | 구조 · 출제 포인트 | 분석지 ⑤⑥번 |
| 5 | 과제 안내 | 학생용 빈칸 분석지 |

이 순서를 고정해야 **강사가 바뀌어도 수업이 같습니다.**
나중에 강사를 쓰게 되면 이 표가 곧 교육 자료가 됩니다.

---

## 6. 레벨 이동 기준

상담 자리에서 "감"으로 말하지 않으려면 숫자가 필요합니다.
`syllabus.yaml` 의 `promotion` 이 그 기준입니다.

- 누적 어휘 테스트 평균 정답률 **85% 이상**
- 출석률 **85% 이상**
- 그 레벨에서 소화한 지문 **48편 이상**

`python manage.py student report S001` 이 세 숫자를 그대로 보여 줍니다.
