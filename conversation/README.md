# 초등 영어 회화 교재 (OPIC 주제 · 초4 눈높이)

OPIC 주제를 초등학교 4학년 수준으로 낮춰 만든 **회화 교재(템플릿 + 워드뱅크)** 생성기입니다.
초등학생에게 어려운 OPIC 주제(직장·출장·은행·호텔 예약 롤플레이 등)는 제외했습니다.

## 구성 (10개 단원)

01 나와 가족 · 02 우리 집 · 03 학교 생활 · 04 취미 · 05 운동
06 음식 · 07 반려동물 · 08 날씨와 계절 · 09 영화와 음악 · 10 여행과 방학

모든 단원은 **똑같은 템플릿**을 따릅니다.

1. **워드뱅크(Word Bank)** — 핵심 단어 + 뜻 + 한글 발음 (단원당 10개)
2. **핵심 표현(Key Expressions)** — 질문/대답 문장 패턴 4개
3. **대화 예시(Sample Dialogue)** — A/B 짧은 회화
4. **나만의 대답 만들기(Make Your Own Answer)** — 빈칸 채워 말하기

마지막에 **전체 워드뱅크 모아보기**(복습용) 부록이 있습니다.

## 만드는 법

```bash
# 최초 1회: 한글 폰트 + PDF 라이브러리
sudo apt-get install -y fonts-nanum
pip install weasyprint

# 교재 PDF 생성
python conversation/build_textbook.py
#  -> output/초등영어회화교재_OPIC10.pdf
```

## 내용 수정

단어·문장·대화는 **`textbook_data.py`** 만 고치면 됩니다.
`UNITS` 리스트에 단원을 추가하면 목차·본문·부록이 자동으로 늘어납니다.
디자인(색·간격)은 `build_textbook.py` 상단의 `CSS` 문자열에서 조정합니다.
색상은 기존 저장소의 5색 팔레트(파랑·초록·보라·노랑·빨강 + 청록)를 따릅니다.
