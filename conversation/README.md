# 영어 회화 교재 (OPIC 주제 · 내 의견 말하기)

OPIC 주제를 바탕으로 **자기 의견을 영어로 말하는** 연습용 회화 교재 생성기입니다.
대화문 없이 **혼자 의견을 말하는** 데 집중하며, **두 가지 버전**을 만듭니다.

| 버전 | 대상 | 데이터 파일 | 산출 PDF |
|---|---|---|---|
| 중학 | 중학생 수준 · OPIC 28개 주제 | `textbook_data.py` | `output/중학영어회화교재_OPIC10.pdf` |
| 성인 | 성인·중급 이상 · OPIC 28개 주제(직장·워라밸·자기계발 + 하루일과·출퇴근·집안일·집밥·수면·주말 등 일상) | `textbook_data_adult.py` | `output/성인영어회화교재_OPIC20.pdf` |

두 버전은 **같은 빌더(`build_textbook.py`)** 와 디자인을 공유하고, 콘텐츠 데이터만 다릅니다.

## 레이아웃 (가로 / 페이지당 1단원)

가로(landscape) A4, **2단 구성**입니다.

- **왼쪽 — 내 의견 말하기 템플릿**: ①주제 소개 → ②내 의견·선호 → ③이유 → ④예시·경험 → ⑤마무리
  의 5단계 문장 틀. 각 빈칸(`____`)에는 빨간 **번호 배지**가 붙습니다.
- **오른쪽 — 워드뱅크(빈칸에 넣을 말)**: 왼쪽 빈칸 번호와 짝을 이루어, 그 빈칸에 넣을 수 있는
  **보기 단어를 번호별로 5개씩, 한글 뜻과 함께** 제시합니다.
  (예: `2 · science 과학 · English 영어 · math 수학 · history 역사 · music 음악`)
  → 학생은 번호를 맞춰 워드뱅크에서 단어(뜻 확인)를 골라 문장을 완성합니다.

한 문장에 빈칸이 여러 개면 번호가 순서대로(1, 2, 3 …) 이어집니다.

## 구성 (OPIC 주제 28개)

01 나와 가족 · 02 우리 집 · 03 학교 생활 · 04 취미 · 05 운동 · 06 음식 · 07 반려동물
08 날씨와 계절 · 09 영화와 음악 · 10 여행과 방학 · 11 자기소개 · 12 친구 · 13 쇼핑 · 14 카페 가기
15 공원 가기 · 16 콘서트·공연 · 17 캠핑 · 18 요리하기 · 19 독서 · 20 명절과 휴일 · 21 국내 여행
22 해외 여행 · 23 게임하기 · 24 인터넷·SNS · 25 TV·드라마 · 26 해변 가기 · 27 사진 찍기 · 28 우리 동네

앞부분에 **사용법 + 5단계 설명 + 목차**, **핵심 표현 모음(의견·연결어)** 페이지가 있고,
맨 뒤에 **부록 · 핵심 단어 사전**이 있습니다. 이 사전은 워드뱅크의 '한 단어' 보기를
알파벳순으로 **자동 수집**해 만들어집니다(별도 작성 불필요).

## 만드는 법

```bash
# 최초 1회: 한글 폰트 + 이모지(흑백) 폰트 + PDF 라이브러리
sudo apt-get install -y fonts-nanum fonts-symbola
pip install weasyprint

# 교재 PDF 생성
python conversation/build_textbook.py          # 두 버전 모두 생성 (기본 all)
python conversation/build_textbook.py school   # 중학 버전만
python conversation/build_textbook.py adult    # 성인 버전만
#  -> output/중학영어회화교재_OPIC10.pdf , output/성인영어회화교재_OPIC20.pdf
```

> **이모지 배치 관련**: WeasyPrint는 컬러 이모지(Noto Color Emoji)를 줄 위로 크게 띄워
> 배치가 어긋나는 버그가 있어, 빌더가 컬러 이모지 폰트를 거부(fontconfig)하고
> **흑백 이모지 폰트 `Symbola`** 로 그리도록 자동 설정합니다. 그래서 `fonts-symbola` 가 필요합니다.
> 이모지는 흑백으로 표시되지만 위치가 정확합니다.

## 내용 수정

- 단어·템플릿 문장은 **`textbook_data.py`** 만 고치면 됩니다.
  - `UNITS` 의 각 단원: `prompt`(OPIC 질문), `template`(5단계 문장), `words`(어휘)
  - `EXPRESSIONS` : 공통 '의견 말하기' 연결어 표현 모음
- 디자인(색·간격·가로/세로)은 `build_textbook.py` 상단의 `CSS` 문자열에서 조정합니다.
  색상은 기존 저장소의 5색 팔레트(파랑·초록·보라·노랑·빨강 + 청록)를 따릅니다.
