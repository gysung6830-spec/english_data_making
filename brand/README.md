# Ortica 블로그 브랜드 이미지 키트

네이버 블로그·티스토리에 바로 올릴 수 있는 이미지 세트와, 글마다 썸네일을
찍어내는 생성기입니다. 결과물은 모두 `brand/assets/` 에 있습니다.

---

## 1. 브랜드 기본

**Ortica(오르티카)** 는 이탈리아어로 *쐐기풀*. 밟혀도 다시 올라오고, 만지면
따끔한 풀입니다. 로고마크는 톱니(거치)가 살아 있는 쐐기풀 잎 한 장으로,
"지문 한 장을 끝까지 파고든다"는 블로그 성격과 맞췄습니다.

| 이름 | 값 | 쓰임 |
| --- | --- | --- |
| Green 900 | `#10382C` | 가장 어두운 배경, 딥 테마 |
| Green 700 | `#1B5A46` | 주색 · 밝은 배경 위 글자 |
| Green 500 | `#2E8B6B` | 보조 |
| Leaf | `#8ACB5E` | 잎 · 포인트 · 딥 배경 위 강조 |
| Cream | `#F5F0E2` | 밝은 배경 |
| Paper | `#FFFDF7` | 가장 밝은 배경 |
| Gold | `#DCA945` | 회차 번호 등 짧은 강조 |
| Muted | `#7E9086` | 부가 설명 글자 |

글꼴은 저장소에 이미 있는 **나눔스퀘어라운드**(`templates/fonts/`)를 씁니다.
분석지 PDF와 같은 글꼴이라 블로그와 배포 자료의 인상이 이어집니다.

## 3. 글마다 썸네일 찍기

포스트 하나당 대표 이미지를 한 줄로 만들 수 있습니다.

```bash
python brand/build.py thumb \
  --title "빈칸추론이 안 풀리는<br>진짜 이유 3가지" \
  --sub "지문 구조부터 다시 보는 독해법" \
  --tag "수능 독해" \
  --number "No.01" \
  --out brand/assets/post-001.png
```

| 옵션 | 설명 |
| --- | --- |
| `--title` | 제목. 줄을 나눌 자리에 `<br>` 를 넣으면 그대로 줄바꿈됩니다. |
| `--sub` | 제목 아래 한 줄 설명 (생략 가능) |
| `--tag` | 왼쪽 위 카테고리 알약 (생략 가능) |
| `--number` | 연재 회차 표기 (생략 가능) |
| `--size` | 기본 `800x800`. 공유 미리보기용은 `1200x630` |
| `--dark` | 딥그린 배경으로 |

글자 크기는 제목의 줄 수와 가장 긴 줄 길이를 보고 자동으로 줄어듭니다.
제목이 길면 `<br>` 로 직접 끊어 주는 편이 보기 좋습니다.

**추천 운영 방식** — 정사각 `800x800` 을 본문 맨 위 대표 이미지로 쓰고,
같은 제목으로 `1200x630` 을 하나 더 뽑아 공유 미리보기용으로 두면
목록·카톡 공유 어디서든 통일감이 유지됩니다.

## 4. 전체 다시 만들기

```bash
pip install pillow          # 최초 1회 (이미지 자르기·축소용)
python brand/build.py all
```

문구·색을 바꾸려면:

- 문구(브랜드명·태그라인·키워드) → `brand/build.py` 위쪽 `BRAND_KO`,
  `TAGLINE`, `KEYWORDS`
- 색 → `brand/ortica_brand.py` 의 `PALETTE`
- 잎 모양(톱니 개수·깊이·잎 비율) → `brand/ortica_brand.py` 의 `leaf_path`,
  `logomark_svg`

렌더링은 헤드리스 크로미움을 그대로 부릅니다. 다른 PC 에서 크로미움을 못
찾으면 실행 파일 경로를 환경변수로 알려 주세요.

```bash
CHROME_BIN="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  python brand/build.py all
```
