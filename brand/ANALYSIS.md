## 0. 판매 문구를 받고 정정한 것

제가 PDF 만 보고 읽은 것과 대표가 쓴 문구가 세 군데 달랐습니다.

| 제가 읽은 것 | 실제 |
| --- | --- |
| '형광펜 독해 학습지' 라는 별개 자료 | **지문분석지**입니다. 전에 말씀하신 '포인트박스 있는 버전'이 이것입니다 |
| 골드 박스 = 지칭·함축 정리 | **함축의미 카드** — 시중에 없는, 이 자료만의 무기 |
| 오답 분류는 무관·부분·모순·지엽 4가지 | 해설 표기는 그렇지만, 설계 원리는 **평가원식 5축**(범위·방향·표면어휘·근거없음·초점이동) |
| 동형모의고사 = 시간 운용 연습 | 시간 운용에 더해 **'우리 학교 동형'** 이 핵심. 실제 시험지의 유형·배점·난이도·레이아웃 재현 |

필생보도 강의용과 독학용을 **각각 하나의 상품**으로 나눴습니다. 판매 문구가
따로 있고 사는 사람도 다릅니다.

## 1. 한눈에

여덟 자료는 따로 만든 여덟 상품이 아니라 **한 지문을 여러 번 통과시키는 한
줄기**입니다. 이 점이 팔 때 가장 먼저 말할 것입니다.

```
읽는 자료
  01 지문자료          기본 자료. 판형 3옵션 — 원문만 / 위아래 해석 / 좌우 해석
  02 지문분석지        보기 쉬운 어법 · 지칭 디자인 · 함축의미 출제 포인트 · 유의어/반의어
시그니처 자료
  03 필생보 ★         능동적 학습 일곱 가지 · O·X·△ 판단 · 학생용/강의용 두 벌
  04 필생보 · 독학용 ★  내 해석을 쓰고 고친다 · 독해 원리 12쪽
쓰는 자료
  05 통합 워크북       다른 데 없는 유형 여섯 · 영작 두 판 · 한글 포함/제외
  06 서술형 대비       학교에 나올 유형 전부 · 조건영작 난이도 조절
  07 17종 변형문제 ★   17유형 · 난이도 중상 · 평가원식 오답 설계 · 유형별 설계
  08 동형모의고사 2회   시간 운용 · 유형별 최적 지문 · 2회로 학교시험 방어
```

**01 은 차별화를 내세우지 않습니다.** 기본 자료라 팔 것이 판형 선택뿐입니다.
여기서 무리하게 차별점을 만들면 나머지 자료의 차별점까지 같이 싸구려가 됩니다.

★ **필생보가 시그니처입니다.** 브랜드 문장(필자의 생각이 보이는 영어)과 자료
이름이 같고, '이렇게 읽으면 오답'은 경쟁 자료에서 본 적 없는 구성입니다.
판본이 셋(강사용·학생 문제지·독학용 교재)이라 파는 폭도 가장 넓습니다.

## 2. 자료별 분석

### ① 지문자료 (원문)

**구성** — 문항 번호(`2026 모의고사 영어독해 26번`), 지문 요지 한 줄,
문장마다 붙은 ①②③ 번호, 하단 저작권 줄.

**판형 3옵션**

| 옵션 | 생김새 | 쪽수 | 쓰기 좋은 자리 |
| --- | --- | --- | --- |
| 원문만 | 요지 한 줄 + 문장 번호 | 지문당 1쪽 | 수업 전에 먼저 읽히기 |
| 위아래 해석 | ① 영어 아래에 ① 한글 (해석에도 번호) | 지문당 1~2쪽 | 숙제 — 해석 쪽을 손으로 가리고 확인 |
| 좌우 해석 | 왼쪽 영어, 오른쪽 해석 (번호 없음) | 지문당 1쪽 | 수업 — 한 쪽에 지문이 다 들어와 훑기 |

**차별화 포인트는 잡지 않습니다.** 기본 자료입니다. 요지 한 줄이 앞에 오고
문장 번호가 라인업 전체와 이어진다는 것은 사실이지만, 그것으로 팔지 않습니다.
사는 사람이 여기서 하는 결정은 **어느 판형을 쓸까** 하나뿐입니다.

**팔 때 쓸 한 줄** — "지문 한 편을 세 가지 판형으로."

### ② 필생보 — 필자의 생각이 보이는 영어독해

블로그 콘셉트와 이름이 같은 **시그니처 자료**입니다. 지문 하나가 5단계를
지나는데, 다섯 단계 내내 **학생이 손으로 합니다.** 이 자료의 키워드는
**능동적 학습** 하나이고, 나머지 특징은 다 그 아래에 붙습니다.

**학생이 직접 하는 일곱 가지** — ① 해석을 빈칸으로 채우기 · ② 어법칩을 문장에서
찾아 ○표 · ③ 문장의 역할·내용·필자의 의견을 O·X·△로 판단하고 근거 고쳐 쓰기 ·
④ 핵심 문법 설명 채우기와 영작 · ⑤ 재진술 사슬 잇기 · ⑥ 글 내용 순서 정리 ·
⑦ 어휘 리스트(문장 번호 표시).

| 단계 | 하는 일 |
| --- | --- |
| 1 지문 통째로 읽기 | 번호 붙은 전문을 흐름부터 훑기 |
| 2 어휘 리스트 | 핵심 어휘 — **앞 숫자가 그 단어가 나온 문장 번호** |
| 3 문장별 끊어읽기 & 내용 파악 | 끊어읽기 슬래시 + **어법칩 ○표** + 해석 빈칸 + **O·X·△ 판단** + **이렇게 읽으면 안 돼** |
| 4 글 정리 | 소재 / 글의 구조 / **재진술 사슬** / 도입·전개·근거·결론 |
| 5 이 지문의 핵심 문법 | 문법 **하나**만 — 설명 빈칸 + 객관식 3~4 + 영작 |

**실제로 다른 점 — 이 자료의 핵심 무기**

**1) O · X · △ — 답이 맞아도 근거가 틀리면 △**

문장마다 진술을 하나씩 주고 학생이 O·X·△로 판단합니다. 결론은 맞는데 근거가
틀린 진술이 △이고, X·△를 고른 학생은 **근거를 바르게 고쳐 적어야** 합니다.

> △ 학생들이 지각하는 것이 이상하지 않은 이유는 교사가 지각을 벌하지 않기 때문이다.
> → 바르게: 본문 대조 `they have little reason to be on time` — 지각이 이상하지
> 않다는 방향은 맞으나, 이유는 벌이 아니라 제시간에 올 이유가 거의 없어서임 [인과조건]

고르기만 하는 O/X 는 반이 찍기입니다. **△ 한 칸이 "어쩌다 맞힌 것"을 걸러
냅니다.** 지칭 문항도 같은 형식으로 나옵니다.

여기에 학생용에만 있는 **'이렇게 읽으면 안 돼'** 가 문장 옆에 붙습니다. 학생이
실제로 하는 오독과 바르게 읽는 법을 같이 적어 둬서, 답을 보기 전에 자기 오독을
알아챕니다.

**2) 재진술 사슬**

같은 소재가 지문 안에서 어떻게 말을 바꿔 다시 나오는지를 번호로 잇습니다.
`seek the company of others` → `seeking companionship`. 빈칸·주제 문항이
정확히 이 자리를 묻습니다. **흑백 인쇄에서도 번호로 구분되게 설계**해서
형광펜 없이도 작동합니다.

**3) 글의 구조를 고르게 합니다**

통념→반박 / 주장→근거·예시 / 문제→해결 / 비교·대조 / 시간·순서 / 예시→일반화.
여섯 중 하나를 **학생이 고릅니다.** 답을 주는 게 아니라 판단을 시킵니다.

**4) 핵심 문법은 지문당 딱 하나**

문법을 나열하지 않습니다. 그 지문에서 진짜 걸리는 것 하나를 골라, 설명 빈칸 →
객관식 → 영작으로 세 번 확인합니다.

**5) 어휘에 문장 번호가 붙습니다**

`4 approval 인정` — 4번 문장에 나온 단어. 단어를 외우다 막히면 그 문장으로
바로 돌아갑니다.

**팔 때 쓸 한 줄** — "읽히지 않습니다. 하게 합니다."

### ③ 워크북 — 내신 서술형·변형문제 대비

**구성** — 한 PDF 안에 4단.

| PART | 내용 |
| --- | --- |
| 1 학생용 | 문제만 |
| 2 교사용 | 같은 문제에 정답·해설 표시 |
| 3 빠른 정답 | 해설 없이 정답만 (즉시 채점용) |
| 4 정답 및 해설 | 유형별 풀이 |

수록 유형 7종 — 보기 어휘 빈칸 완성 / 서술형 요약문 완성 / 어법 오류 수정 /
조건 영작 / 요지·제목 배열 영작 / 문장 변형 대비 / 지문 기반 영어 문답.

**실제로 다른 점**

**1) 조건 영작에 난이도 3단 제시어**

같은 문장을 **하·중·상** 세 단계로 냅니다. 하는 단어를 많이 주고, 상은 거의
안 줍니다.

> 하 `curiosity child ask who retain long encourage question`
> 중 `retain encourage child curiosity`
> 상 `encourage`

**한 반에 실력 차가 있어도 같은 문장을 같이 시킬 수 있습니다.** 이건 학원
수업에서 바로 값이 되는 기능입니다.

**2) 학생용·교사용·빠른 정답이 한 파일에**

교사용을 화면에 띄워 수업하고, 빠른 정답으로 즉시 채점합니다. 파일을 여러 개
받아 관리할 필요가 없습니다.

**3) 채점 기준을 미리 밝힙니다**

"모든 정답과 근거는 지문 내용에만 근거합니다(임의 추론 없음)",
"조건을 지킨 동의 표현도 정답 처리". 서술형에서 늘 생기는 실랑이를
**자료가 먼저 정리해 둡니다.**

**팔 때 쓸 한 줄** — "실력이 다른 학생들에게 같은 문장을 시킬 수 있습니다."

### ④ 17종 변형문제

**구성**(2026 개정판) — 회차로 나누던 것을 **한 지문 통합본 17문항**으로
묶었습니다. 학생용 문제 → 교사용(문제 + 해설) → 빠른 정답 → 정답 및 해설.
유형별로 한 문항씩, 같은 지문을 열일곱 번 다른 각도로 묻습니다.

> 이전 판과 달라진 것 — 어법 '개수' 문항이 **어법 서술형**(틀린 것 4개를 찾아
> 바르게 고쳐 쓰기)으로 바뀌었고, **내용 O/X**(진술 10개)와 그 **영어판**,
> **연결어 (A)·(B)** 가 새로 들어왔습니다. '무관한 문장'은 빠졌습니다.

**실제로 다른 점**

**1) 오답 이유를 유형으로 분류합니다**

해설이 "틀렸다"로 끝나지 않고 오답마다 이름을 붙입니다.

> ② 하드 드라이브가 분자를 대체한다는 내용 없음 **(무관)**
> ⑤ 가격 비교가 주제가 아님 **(부분)**
> ④ 취약성이 아니라 내구성이 논지 **(모순)**
> ④ 발견 경위는 지엽 **(지엽)**

무관 · 부분 · 모순 · 지엽 — 이건 해설에 찍히는 **표기**입니다. 그 뒤의 **설계
원리는 평가원식 5축**입니다: 범위 비틀기 · 방향 반전 · 표면 어휘 함정 ·
근거 없음 · 초점 이동. 여기에 정답과 한 끗만 다른 매력적 오답을 하나 넣어
**소거법이 통하지 않게** 합니다.

정답 선지는 지문 단어를 베끼지 않고 유의어로 재진술합니다. '원문에서 본 것 같은'
선지가 오히려 함정입니다.

**원문을 그대로 두는 문항과 표현을 바꿔 낸 문항이 섞여 있습니다.** 그대로 두는
쪽은 틀렸을 때 원문으로 돌아가 근거를 짚게 하고, 바꿔 낸 쪽은 지문을 통째로
외워 온 학생을 걸러 냅니다. 실전에서 표현이 조금만 바뀌어도 무너지는 학생을
여기서 먼저 만나게 하는 것이 목적입니다.
모든 문항이 3단계 검증을 거치고, 애매할 수 있는 것만 맨 끝 확인 페이지에 모읍니다.

**2) 수록 유형 17가지 — 수능 몇 번에 대응하는지까지**

| 유형 | 수능 대응 | | 유형 | 수능 대응 |
| --- | --- | --- | --- | --- |
| 주제 | 23번 | | 어휘 — 원문 단어형 | 30번 |
| 제목 | 24번 | | 어휘 — 유의어형 | 30번 |
| 함의추론 | 21번 | | 어휘 — 부정어형 | 30번 |
| 내용 O/X (진술 10개) | 26번 계열·내신 | | 빈칸추론 | 31~34번 |
| 내용 O/X (영어) | 내신 | | 연결어 (A)·(B) | 내신 |
| 어법 — 틀린 것 모두 고르기 | 29번 | | 순서 배열 | 36~37번 |
| 어법 서술형 — 4개 고쳐 쓰기 | 내신 서술형 | | 문장 삽입 | 38~39번 |
| 어법·어휘 짝짓기 | 내신 | | 요약문 빈칸 | 40번 |
| | | | 어순 배열 | 내신 서술형 |

어법만 셋(모두 고르기 · 서술형 · 짝짓기), 어휘만 셋(원문형 · 유의어형 ·
부정어형)입니다. **수능에 없고 내신에만 나오는 형태(어법 서술형 · 짝짓기 ·
내용 O/X 영어판 · 연결어 · 어순 배열)를 따로 넣었다는 것**이 이 표의 값입니다.
학교 시험지에 나오는데 시중 변형문제집에는 없는 자리입니다.

**3) 유형마다 설계가 따로 있습니다**

- **어법 — 모두 고르시오.** 단일 정답이 아니라 복수 정답입니다. 찍어서 맞히는
  길을 막습니다.
- **어법은 지문을 다시 써서 냅니다.** 원문 그대로 두면 문장을 외운 학생이
  눈으로만 훑고 맞힙니다. 같은 내용을 다른 문장으로 다시 적고 그 위에 밑줄을
  칩니다.
- **순서 배열은 A-B-C-D 네 덩어리.** 세 덩어리로 끊으면 첫 문장만 보고 답이
  좁혀집니다. 넷으로 자르면 연결 고리를 세 번 판단해야 합니다.
- **연결어는 모든 지문에.** 원문에 연결어가 없는 지문에도 (A)·(B) 자리를 만들어
  냅니다. 앞뒤 관계를 추론해서 고르게 하려는 것이라, 어느 지문을 받아도 이
  유형이 빠지지 않습니다.
- **어휘 세 종은 비트는 방식이 다릅니다.** 같은 30번 유형인데 찾는 방식이
  매번 달라져서, 한 방식에 익숙해진 눈으로는 다음 문항에서 걸립니다.

  | 유형 | 방식 | 밑줄 5개가 원문과 다른가 |
  | --- | --- | --- |
  | 원문형 | 정답 1개만 반의어 | 1개만 다름, 4개는 원문 그대로 |
  | 유의어형 | 5개 전부 교체 (정답=반의어, 4개=유의어) | 5개 전부 다름 |
  | 부정어형 | 밑줄은 원문 그대로, 정답 문장에 부정어 삽입 | 0개 (문장 하나가 바뀜) |

- **어법·어휘를 한 문항에서 같이.** 밑줄 ⓐ~ⓔ 중 어떤 것은 어법이, 어떤 것은
  문맥상 낱말이 틀렸습니다. 둘을 섞어 놓고 '적절하지 않은 것끼리' 짝지어 고르게
  하니 어법 따로 어휘 따로 공부한 학생은 어느 쪽으로 봐야 할지부터 막힙니다.
- **내용 일치는 진술 열 개.** 주어 바꾸기 · 인과 뒤집기 · 완료/미완료 바꾸기 ·
  범위 넓히기 — 낼 수 있는 경우의 수를 한 문항에 다 담습니다. 영어로 낸 판까지
  따로 있습니다.

**4) 난이도는 중상 하나로 — 변별력 확보**

하·중·상을 층으로 쌓지 않습니다. **중상 한 층**에 맞춰 냅니다. 쉬운 문항으로
문항 수를 채우면 다 맞히고 지나가서 아무것도 안 걸러집니다. **학생이 틀리는
지점을 위주로** 설계해야 "여기서 틀려야 학교에서 맞는다"가 성립합니다.

**5) 어휘 오답에 출제 방식 태그**

`[반의어형]` 처럼 어떻게 비틀었는지를 해설에서 밝힙니다.

**팔 때 쓸 한 줄** — "왜 틀렸는지를 네 가지 이름으로 정리해 줍니다."

### ⑤ 지문분석지 (구 '형광펜 독해 학습지')

**구성** — 맨 앞에 '이 학습지 100% 활용법'. 색과 기호의 뜻을 먼저 약속하고
시작합니다. 이후 지문마다 앞면(영어 원문 + 표시)과 뒷면(어휘·논리 흐름).

| 표시 | 뜻 |
| --- | --- |
| 회색 S V O C | 문장 성분 — 단어 위에 |
| 노란 형광 + 빨간 ①②③ | 핵심 어법 — 오른쪽 민트 박스와 짝 |
| `whom(X)` | 오답형 함정 — 그 자리에 넣으면 틀리는 형태 |
| 본문 동그라미 ⓐⓑⓒ | 대명사 지칭 — 오른쪽 골드 박스와 짝 |
| 검정 테두리 박스 | 주제문 · 빈칸 출제 예상 어구 / 담화표지 |
| 골드 박스 | 대명사 지칭 · 숨은 함축 의미 |
| 유의어 · 반의어 | 뒷면 어휘표에서 정리 (= 유의어 · ↔ 반의어) |

> 2026 개정판에서 표기가 바뀌었습니다 — 어법이 빨간 글자에서 **노란 형광 +
> 빨간 번호**로, 주제문·담화표지가 형광에서 **검정 테두리 박스**로, 지칭은
> 본문에 **동그라미 ⓐⓑⓒ**를 달아 오른쪽 골드 박스와 짝을 지었습니다.
> 유의어·반의어는 본문 밑줄 대신 뒷면 어휘표로 모았습니다.

**실제로 다른 점**

- **읽는 규칙을 먼저 약속합니다.** 대부분의 분석지는 표시를 해 놓고 뜻은
  설명하지 않습니다. 여기는 범례가 1쪽입니다.
- **오답형 함정을 그 자리에 같이 보여 줍니다.** `who(X)` 처럼 넣으면 틀리는
  형태를 정답 옆에 둡니다. 필생보의 '이렇게 읽으면 오답'과 같은 철학입니다.
- **본문 번호와 오른쪽 박스가 짝**이라, 색을 먼저 보고 이유를 확인하는
  순서가 지면에 박혀 있습니다.

대표 문구로는 **핵심 넷**입니다.

1. **보기 쉬운 어법** — 노란 형광 + 빨간 번호가 오른쪽 민트 박스와 짝. 정답 옆에
   `whom(X)` 처럼 넣으면 틀리는 형태를 같이 둡니다.
2. **지칭 디자인** — 본문 동그라미 ⓐⓑⓒ 와 오른쪽 골드 박스가 선으로 이어집니다.
   '무엇을 가리키는지 생각해 보라'로 끝내지 않습니다.
3. **함축의미 출제 포인트** — 문맥상 의미 · 시험이 정답으로 쓰는 영어 표현 ·
   직역하면 빠지는 함정, 세 줄이 한 카드에. 빈칸추론·함축추론을 정면으로
   대비하는, 이 자료만의 무기.
4. **유의어·반의어까지** — 핵심 어휘를 뜻만 적고 끝내지 않고 유의어·반의어를
   나란히, 몇 번 문장에 나왔는지까지. 어휘 문항이 유의어로 바꿔 내는 자리입니다.

여기에 직독직해 1:1(영어 끊어읽기와 한글 해석의 위치를 정확히 맞춤)과, 논리
흐름도·학생용 빈칸 복습·단어 테스트·원문 해석까지 한 세트로 붙습니다.

**팔 때 쓸 한 줄** — "어디를 봐야 하는지가 지면에 그려져 있습니다."

### ⑥ 통합 영어 워크북 (한글 포함 / 한글 제외)

**구성**(2026 개정판, 올림포스 10-2 기준 248쪽) — 지문 하나에 아홉 장.
어형 변형 → 어법 양자택일 → 어휘 양자택일(하) → 어휘(상, 셋 중 두 개) →
**영작① 함정 단어** → **영작② 어형 변형** → 지문 빈칸·요약문 빈칸 →
대명사 지칭 → 통합 카드 → 한글 해석 연습. 유형마다 [문제] 바로 뒤에
[정답·해설]이 붙습니다.

> 이전 판과 달라진 것 — 영작이 한 장에서 **두 장으로 갈렸습니다.** ①은 〈 〉
> 안에 쓰이지 않는 '함정 단어'를 하나씩 섞어 두고, ②는 ( 원형 )으로 준 단어를
> 어형까지 바꿔 배열하게 합니다. 통합 카드는 맨 뒤로 갔고, 유형 이름표에 색이
> 붙었습니다.

**실제로 다른 점**

- **남들이 안 다루는 대명사 지칭까지.** it·they·this 가 무엇을 가리키는지 짚는
  문항이 들어 있습니다. 독해력의 실제 승부처인 지칭을 그냥 넘어가지 않습니다.
- **영작이 두 판입니다.** ① 함정 단어를 골라내고 배열, ② ( 원형 )을 어형까지
  바꿔서 배열. 어순만 외운 학생은 ①에서, 어형을 모르는 학생은 ②에서 걸립니다.
  문장 전체를 다시 쓰게 하지 않아 한 문장 쓸 시간에 세 문장을 봅니다.
- **한 문장에 과제를 겹쳐 놓습니다.** 같은 문장에서 동사 어형과 형용사 선택,
  관계사, 연결사, 지칭을 한꺼번에 묻습니다.
- **오류 없는 문항.** 수일치 오류·정답 쏠림·중복을 전수 검증으로 제거하고 정답
  위치를 분산해 찍기가 통하지 않습니다. 어느 프린터에서도 글자가 안 깨집니다.
- **한글 포함본과 한글 제외본을 함께 냅니다.** 같은 학생이 두 번 풀 때
  난이도가 달라집니다. 파는 쪽에서는 한 지문으로 두 자료가 나옵니다.
- **채점하러 뒤로 넘길 필요가 없습니다.** 문제 바로 뒤가 해설입니다.

**팔 때 쓸 한 줄** — "같은 지문을 해석 있이 한 번, 없이 한 번."

### ⑦ 동형모의고사

**구성** — 학교 시험지 양식 그대로. 코드 03, 1학년, 과목명 영어독해,
제한 시간 30분, 컴퓨터용 사인펜 마킹 안내, 문항별 배점([3점] [4점]),
"지필평가: 총 10문항, 총 4쪽". 뒤에 해설.

**실제로 다른 점**

- **목적이 점수가 아니라 시간 운용입니다.** 30분에 지문 4개. 시간 배분과
  체력을 같이 연습시킵니다.
- **양식까지 학교 시험지입니다.** 코드·학년·과목명·마킹 안내가 그대로
  들어갑니다. 처음 보는 양식에서 당황하는 일을 없앱니다.
- **배점이 문항마다** 붙어 있어 어디에 시간을 쓸지 판단하며 풀게 됩니다.
- **해설이 두 칸**입니다. [핵심 포인트]로 정답 근거를 적고, [오답 함정]으로
  나머지 선지를 따로 답니다.

**대표 문구가 짚은 진짜 핵심** — **"우리 학교 동형"**. 시중 문제집의 남의 시험이
아니라 우리 학교 실제 시험지의 유형·배점·난이도·레이아웃을 그대로 재현합니다.
**2회분**을 내고 두 회차의 문항이 겹치지 않습니다. 시간 운용은 그 위에 얹히는
효과입니다.

**팔 때 쓸 한 줄** — "시중 문제집의 남의 시험이 아니라, 우리 학교 시험지 그대로."

### ⑨ 필생보 독학용 교재 — 따로 볼 값어치가 있는 판본

필생보 셋째 판본입니다. 지문 훈련 앞에 **독해 원리 11강**이 붙습니다.

```
STEP 1 먼저 익히는 독해 원리
  01 독해 태도        점수는 태도에서 나온다
  02 완급조절         OLD / NEW·MAIN / SUPPORT
  03 추론             어순·구두점으로 모르는 걸 추론
  04 연결사 지도      Switching vs Contrast
  05 재진술           같은 말을 알아채기
  06 재진술 5변환·함정  정답이 만들어지는 법
  07 글의 구조        6가지 글의 틀
  08·09 ±어휘 사전    긍정·부정 / 방향 전환
  10·11 논리관계 구문  인과·등호 / 대조·비교
  12 형광펜 신호 사전  무엇을 읽고 버릴까
STEP 2 지문으로 훈련
```

**실제로 다른 점**

- **"완급조절"** — OLD(배경·통념)는 약하게, NEW·MAIN(주제)은 가장 강하게,
  SUPPORT(부연)는 선명하면 약하게. *"완급 없이 직독직해만 하면 남는 정보가
  없다"* 는 문장이 이 교재의 태도를 요약합니다.
- **"재진술 5변환·함정 — 정답이 만들어지는 법"** — 출제자가 정답 선지를
  만드는 방식 자체를 가르칩니다.
- **기출로 원리를 증명합니다.** 2023 6월 37번, 2024 9월 33번처럼 회차를 밝힌
  문장으로 설명합니다.
- **말투가 다릅니다.** "순서대로만 따라와." 혼자 보는 교재라 옆에서 말해 주는
  톤으로 씁니다.

**팔 때 쓸 한 줄** — "지문을 풀기 전에, 읽는 법부터 열한 장으로."

## 3. 여덟을 관통하는 축 셋

라인업 소개글의 뼈대는 이 셋입니다.

### 축 1. 정답이 아니라 오답을 먼저 보여 준다

필생보의 '이렇게 읽으면 오답', 변형문제의 무관·부분·모순·지엽,
형광펜 학습지의 `who(X)` 함정, 동형모의고사 해설의 [오답 함정].
**네 자료가 같은 철학으로 만들어졌습니다.** 시장의 대부분은 정답과 해석만
줍니다. 여기는 틀리는 길에 먼저 이름을 붙입니다.

이게 브랜드 문장 **"필자의 생각이 보이는 영어"** 와 정확히 맞물립니다.
필자의 생각이 보이려면, 안 보였을 때 어떻게 잘못 읽게 되는지를 알아야 합니다.

### 축 2. 문장 번호 하나로 여덟 자료가 물린다

지문자료·한줄해석·필생보·형광펜 독해·워크북·변형문제가 같은 번호를 씁니다. 수업 중
"7번 문장"이면 학생이 어느 자료를 펴고 있든 같은 자리를 봅니다.
**낱개로 사도 되지만, 묶어서 사면 값이 배가 되는 구조**입니다. 패키지 판매의
근거가 여기 있습니다.

### 축 3. 가르치는 사람과 혼자 하는 사람을 갈라 놓는다

필생보는 강사용·학생 문제지·독학용 교재 셋, 내신 서술형 워크북은
학생용·교사용·빠른 정답, 통합 워크북은 한글 포함본·제외본. **같은 내용이라도
앞에서 설명할 때와 혼자 앉아 볼 때 필요한 지면이 다르다**는 걸 자료가
인정하고 만들어졌습니다. 강의용 라이선스를 따로 값 매길 근거이기도 합니다.

[본문1] 01-04  읽는 자료   지문자료 · 한줄해석 · 필생보★ · 형광펜 독해

## 5. 상세 포스팅에 쓸 순서 (자료 공통)

1. **이 자료가 없을 때 생기는 일** — 문제를 먼저. ("해석지를 줬는데 학생이 계속 같은 문장에서 막힙니다.")
2. **실제 지면 한 장** — 설명보다 먼저 보여 줍니다.
3. **다른 점 두세 개** — §2의 '실제로 다른 점'에서 골라 씁니다.
4. **구성표** — 몇 쪽, 몇 유형, 어떤 판본
5. **이런 분께** — 강사 / 학생 나눠서
6. **가격과 사는 법**
7. **직접 쓴 한 문단** — 수업에서 있었던 일. ([VOICE.md](VOICE.md) §4)

  분석해 라인업에 넣겠습니다.

  잘 먹힙니다. "강사용은 채워져 있고 학생용은 비어 있습니다" 한 줄이면
  두 판본을 같이 파는 이유가 설명됩니다.
