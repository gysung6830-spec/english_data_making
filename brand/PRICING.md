# 가격 설계 — 근거와 확인해야 할 것

**결론부터: 아래 숫자는 확정가가 아니라 제안가입니다.** 이 작업 환경에서 네이버
블로그, 쏠북 상품 페이지, 오르비 자료실 같은 국내 사이트에 직접 접속이 막혀
있어서, 경쟁 자료의 실판매가를 눈으로 확인하지 못했습니다. 확인한 것과 추정한
것을 아래에 나눠 적었습니다. 확정 전에 §4를 반드시 채워 주세요.

---

## 1. 확인된 사실

| 사실 | 출처 |
| --- | --- |
| 쏠북은 PDF 판매가를 열람·출력 판매가의 **2배**로 자동 설정한다 | 쏠북 저자 가이드 |
| 아잉카는 모의고사·수능기출 **자유이용권 60,000원** 구독형으로 판다 | 아잉카 |
| 너른터는 기출·내신 **변형문제를 AI 자동출제로 무료** 제공한다 | 너른터 |
| 연계소문(수능완성 영어변형문제)은 **출판 교재**로 유통된다 | 교보문고 |

여기서 읽어야 할 것은 세 가지입니다.

**변형문제는 단품으로 비싸게 받기 어렵습니다.** 무료 AI 출제 서비스가 이미
있습니다. 값을 받으려면 "자동 생성이 못 하는 것"이 팔려야 합니다 — 지문 선별,
오답 설계, 해설의 밀도.

**구독·자유이용권이 상단 가격대를 잡고 있습니다.** 6만 원이 "다 쓰는 값"으로
인식되면, 단품을 그에 근접하게 매기기 어렵습니다. 대신 묶음 단가를 낮추고 회전을
올리는 쪽이 맞습니다.

**플랫폼에 얹으면 단가는 내려가고 수량은 올라갑니다.** 블로그 직판은 그 반대입니다.
직판 가격을 플랫폼가에 맞출 이유가 없습니다.

## 2. 값을 매기는 기준

자료마다 **제작에 드는 시간**과 **사는 사람이 아끼는 시간**이 다릅니다. 이 둘의
비율로 층을 나눴습니다.

| 층 | 성격 | 해당 |
| --- | --- | --- |
| 낮은 층 | 있으면 편하지만 없어도 수업이 굴러감 | 한줄해석 |
| 중간 층 | 직접 만들면 지문당 30분 이상 걸림 | 워크북 |
| 높은 층 | 만들려면 출제 감각이 필요함 | 지문분석지, 변형문제 6종 |
| 실전 층 | 회차 단위로 값이 매겨짐 | 동형모의고사 |
| 라이선스 층 | 쓰는 범위가 값을 가름 | 필생보 (강의용/독학용) |

## 3. 제안가

### 자료 (PDF)

| 자료 | 낱개 | 묶음 | 왜 이 값인가 |
| --- | --- | --- | --- |
| 한줄해석 | 지문당 500원 | 20지문 8,000원 | 진입용. 이걸 사고 다른 걸 보게 만드는 자리 |
| 지문분석지 | 지문당 1,500원 | 20지문 25,000원 | 6섹션 4~6쪽. 직접 만들면 지문당 1시간 |
| 워크북 | 지문당 1,000원 | 20지문 16,000원 | 분석지에 얹어 파는 자리. 분석지의 3분의 2 |
| 변형문제 6종 | 지문당 1,500원 | 20지문 25,000원 | 무료 대체재가 있으니 해설 밀도로 값을 받는다 |
| 동형모의고사 | 1회 5,000원 | 5회 20,000원 | 회차 단위. 5회 묶으면 1회분을 얹어 주는 셈 |
| 필생보 | 독학용 12,000원 | 강의용 30,000원 | 값의 차이는 분량이 아니라 **쓰는 범위** |

### 제작 교재 (고3)

| 교재 | 가격 | 근거 |
| --- | --- | --- |
| 형광펜 독해 | 22,000원 | 시중 고3 독해 교재 상단 가격대에 맞춤 |
| 구문독해 | 22,000원 | 위와 동급 |
| 평가원 VOCA | 18,000원 | 단어장은 독해서보다 한 단 아래로 인식됨 |

### 묶어 파는 자리

- **지문 풀세트** (한줄해석 + 분석지 + 워크북 + 변형문제, 20지문) — 낱개 합
  74,000원 → **59,000원**. 20% 낮춰 세트를 기본 선택지로 만듭니다.
- **학원 라이선스** — 자료 가격의 **3배**, 수업 배포 허용. 한 부를 사서 20명에게
  나눠 주는 상황을 값 안으로 끌어들이는 유일한 방법입니다.

### 값을 정할 때 지킬 것

첫 상품은 낮게 시작해도 됩니다. 하지만 **한번 매긴 값을 올리는 건 내리는 것보다
훨씬 어렵습니다.** 초기 할인은 "값"이 아니라 "기간 한정"으로 표시하세요.
"9,900원" 같은 끝자리는 이 브랜드 톤과 맞지 않습니다. 1,000원 단위로 딱 떨어지게
두는 편이 자료의 격을 지킵니다.

## 4. 확정 전에 채워야 할 칸

직접 확인해서 아래를 채운 뒤 `brand/catalog.py` 의 `price` 를 고치고
`python brand/build.py all` 을 다시 돌리면 가격표 이미지까지 함께 갱신됩니다.

- [ ] 벤치마킹 블로그(bsh_english)의 자료별 실판매가 — 특히 분석지·변형문제
- [ ] 쏠북에서 같은 성격 자료의 열람가 / PDF가
- [ ] 경쟁 자료의 **묶음 단위** (20지문인지, 회차 전체인지)
- [ ] 학원 라이선스를 따로 파는 곳이 있는지, 배수는 얼마인지
- [ ] 결제 수단 (네이버 폼 / 스마트스토어 / 크몽 / 직접 계좌) 과 수수료율
- [ ] 교재의 실제 인쇄·제본 단가와 배송비

특히 **필생보**는 제가 정체를 모른 채 가격을 매겼습니다. 무엇을 담는 자료인지
알려 주시면 층을 다시 잡겠습니다.
