# 통합 영어 워크북

![](detail-05-workbook-integrated.png)

어형 변형·어법·어휘·대명사 지칭·영작 2종·해석·빈칸을 한 지문 안에서 다 묻습니다. 유형별로 자료를 사 모아 지문을 맞춰 붙이던 일이 없어집니다. 문제 바로 뒤에 정답과 해설이 있어 학생이 혼자 풀고 바로 채점합니다.

## 무엇이 들어 있나

**한글 포함본과 제외본, 두 벌이 옵니다**

해석을 보며 한 번 풀고, 해석을 뗀 판으로 한 번 더 풉니다. 같은 학생이 두 번 푸는데 난이도가 달라져서 복습용과 시험 대비용을 따로 살 필요가 없습니다.

**다른 워크북에는 없는 유형이 들어 있습니다**

어형·어법·어휘로 끝나지 않습니다. 대명사·지시어가 가리키는 대상을 [ ]에서 고르게 하고, 어휘는 셋 중 '두 개'를 고르게 해 찍기를 막습니다. 다른 워크북이 그냥 넘어가는, 학생이 실제로 틀리는 자리입니다.

**영작은 두 판, 통째로 외운 학생이 걸립니다**

영작①은 〈 〉 안에 쓰이지 않는 '함정 단어'를 하나씩 섞어 두어 필요 없는 단어를 빼고 배열해야 합니다. 영작②는 ( 원형 )으로 준 단어를 문맥에 맞게 바꾼 뒤 배열해야 합니다. 어순만 외운 학생은 ①에서, 어형을 모르는 학생은 ②에서 걸립니다.

**빈칸도 채우게 합니다**

지문 빈칸은 첫 글자 힌트를 주고, 요약문 빈칸은 워드뱅크에서 골라 씁니다. 고르는 문항만으로는 안 남는 것이 손으로 쓰면 남습니다.

**한 문장에 여러 유형을 겹쳐 묻습니다**

어형·어법·지칭·영작이 같은 문장에 걸립니다. 유형별로 자료를 사 모아 붙이면 지문을 그만큼 여러 번 읽어야 하는데, 여기서는 한 번 읽고 여러 번 확인합니다.
