# 어법칩 항상표기 보강(GC) 오버레이

`gc_*.json` = 기존 지문 데이터에 **덧붙이는** 추가 어법칩. 규격은 올림포스 배치의
`../../올림포스_기본1_10강-14강_추가/gc/GC_SPEC.md` 참조.

## 형식
```json
{ "<item_no>||<sentence_id>": [ {"tag": "표준용어", "note": "설명", "spans": ["원문 표지 그대로"]} ] }
```
- `tag` = 표준 용어만(문장 속 영어 단어 금지) — `src/tag_terms.py` 정규화 대상.
- `spans` = 그 문장 `english`의 **연속 부분문자열**이자 **독립 단어 경계**(예: `if`가 `difference` 안에 들어가면 안 됨). 강사용 형광펜 위치.
- 숙어·구동사는 넣지 않음(렌더가 자동 승격).

## 적용
빌드 시 각 지문의 문장 grammar 배열에 `<item_no>||<sid>` 키로 매칭해 append
(기존 tag와 중복이면 skip). 적용 후 `verify.py`로 ERROR 0 확인.
