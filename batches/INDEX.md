# 교재 묶음(batch) 인덱스

> **이 파일이 전체 묶음 카탈로그입니다.** 리포지토리(`batches/INDEX.md`)에 있으므로 세션이 끝나도, 다음 세션에서도, GitHub에서도 항상 볼 수 있습니다.
> 각 묶음은 `batches/<이름>/` 폴더에 격리하고 이 표에 기록합니다.
> - **카탈로그·gen 스크립트** = 리포에 커밋 → 영구 보존 (나중에 재생성 가능)
> - **완성 PDF** = 세션 임시폴더에서 생성해 전달(다운로드본이 원본) — 필요 시 해당 묶음 폴더에 함께 커밋 가능
> "지금 무슨 묶음 있어?" 하면 이 표를 보여드립니다.

## 폴더 규칙 (묶음마다 동일)
```
batches/<이름>/
├─ gen.py                  # 지문 데이터 + 렌더 스크립트(이 묶음 전용)
├─ <출처>_학생용.pdf        # 개별/합본 산출물
├─ <출처>_강사용.pdf
└─ (필요 시) 입력 이미지·메모
```
- 새 묶음 시작: 지문과 함께 **"묶음 이름"** 한 줄 주시면 그 이름으로 폴더 생성.
- 이름 미지정 시: 지문 출처(교재·단원)로 자동 라벨링.
- 생성 후 항상 `verify.py`로 검증한 결과를 아래 표에 함께 기록.
